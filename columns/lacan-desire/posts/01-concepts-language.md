# 概念准备（上）：无意识像语言

你为什么会做奇怪的梦？醒过来之后，你通常给它两种说法：要么是秘密——心里藏着的事变了形；要么是乱码——大脑没睡好，瞎拼接。这个系列要一起读拉康（Jacques Lacan）画的一张图：欲望图（graphe du désir / graph of desire），一张把「欲望在语言里怎么被制造、又怎么逃逸」画出来的图。读图之前先打地基，而这期是地基的第一块砖——一句比梦本身更怪的话：梦不是秘密，也不是乱码，它是句子。

## 能指与所指：同一个词，换语境就变味

语言学家索绪尔（Ferdinand de Saussure）把语言符号看成两面一体的硬币：能指（signifiant / signifier，承载声音和字形的那半边）与所指（signifié / signified，概念的那半边）。两面互依、对等，像一枚硬币，翻来翻去都是它。

拉康改写了这个公式。他把它竖起来写成一个算式，中间加一杠：能指在上、所指在下。

```
       S（能指：声音、字形这类可以被区分的材料）
    ─────────────────────────────
       s（所指：概念、意义）
```

然后他翻转了优先级：不是「先有意义，再找词来装」，而是能指在先，所指不是给定的，而是能指的游戏「产生」出来的效果。在索绪尔那里，两面像硬币一样对等；拉康这一杠，把对等取消了——中间那杠不再是中性的分界线，而是宣告能指占着优先：意义不跟词同时到场，它晚一步，是产物。他在 1957 年的《无意识中字母的动因》（《Instance of the Letter》）里写：所指在能指底下不断滑动（"an incessant sliding of the signified under the signifier"）。滑动是常态，不是故障。

试试「你真行」。夸人的时候说「你真行」，对方刚干完一件蠢事之后阴阳怪气地说「你真行」——三个字、同样的读音，意义却完全相反。同一个能指，换一个位置就变味：意义不是词自带的行囊，而是位置与语境生产出来的效果。词和意义之间没有天然的钉子——这正是翻转公式的意思：不是词为意义服务，而是意义在词的位置游戏里生成。

## 语言是链：意义不在词里，在位置关系里

词为什么没有固定意义？因为语言不是词堆成的货架，而是链条。拉康的比喻：能指链（chaîne signifiante / signifying chain，词与词彼此咬合、意义从位置关系里长出来的链条）是「项链环套项链环」——没有一个环能单独承载意义，而每一环都坚持要你往下走（《无意识中字母的动因》）。也可以想成一条传送带：每个词都不是固定的发球点，靠前后位置产生含义；传送带不停，意义就一直在路上。

点菜的「随便」是个试验场。朋友问「想吃什么」，你回「随便」——意思是「我都可以，你拿主意」。恋人问「周末怎么过」，你回「随便」——两个字一模一样，意思却是「你怎么还没猜出我想要什么」。同一个能指，位置一变，所指完全不同。「随便」二字里不藏任何意义；意义藏在它被说出的那条链、那个语境里。

```
   S1 ────→ S2 ────→ S3 ────→ S4 ────→ ……
     ↘         ↘         ↘         ↘
     s1        s2        s3        s4        （所指在底下滑）
```

能指一个接一个，所指一路滑。这条链在图上写作 S→S′：S′ 读作表意（signification），是「意义产生」这个动作本身，不是某个词所指的东西。注意它不是「从词到物」的直线——意义从来不作为「东西」到达，它一直在产生之中。记住这条链的样子：它将是整张图的下层横线，后面每一篇讲的路、圈、叉，都长在这条链上。

## 无意识像语言：梦、口误、症状的语法

现在把链接到人身上。拉康的口号：无意识像语言一样被结构（l'inconscient est structuré comme un langage / the unconscious is structured like a language）。先拆最常见的误解：这不是说「无意识里住着一个小人，用母语对你说话」。它的意思是——梦、口误、症状不是藏起来的秘密，而是像造句一样被组织起来的，用的是替换、拼接、跳转的语法。读懂无意识，就是读懂这种语法。

弗洛伊德（Sigmund Freud）走完了前半程。他管这叫「双重铭刻」（double inscription）：同一个行为，同时载着意识的意义和无意识的意义，两者互相约束。你以为自己在说 A，句子里同时写着 B——口误就是双重铭刻最日常的现场。

有人约好了明天和恋人吃饭，一开口说成「明天我请我妈吃饭」。想说的那个词被另一个词顶替了——「她」的槽位里站进了「我妈」。注意这件事的结构：口误不是乱码，而是一次严格按语法完成的替换。替换需要一条链（句子按顺序展开）和一个槽位（这个位置本来能放哪些词）；出错的是选词这一步，而选词选出了别的东西。无意识「像语言」，证据正在这里：它不直接开口，它用替换和拼接说自己的话。

梦也一样。梦像句子，但是用跳转写成的句子：场景拼接、人物替换、时间倒错。弗洛伊德给这套语法起过两个名字——凝缩与移置——下一节，拉康把它们接到语言学的两根轴上。最后是症状（symptom，那些反复出现、不受你控制的躯体或行为表现）：口误是一次性的，症状是反复出现的同一种「句子」——同一个结巴卡在同一个音节上，同一个动作在同一个场合重演。它们不是生理事故，而是固定句式的重复：语法不变，句子就反复来。

## 隐喻与换喻：意义怎么动

雅各布森（Roman Jakobson）1956 年指出，语言有两根轴：聚合轴（paradigmatic，选择与替代——这个槽位可以换成别的词）与组合轴（syntagmatic，序列与连接——词按顺序拼接）。拉康把弗洛伊德的两个机制接到这两根轴上：凝缩（condensation，好几个东西压进一个符号）对应隐喻（métaphore / metaphor，一个词顶替另一个词）；移置（déplacement / displacement，意义从一能指挪到下一能指、被推远）对应换喻（métonymie / metonymy，意义顺着链滑走、被延宕）。这是通行对应，别写反。

隐喻像一锤子换名字。拉康的公式：「一辞代另一辞：这是隐喻的公式」（"one word for another: this is the formula for metaphor"）。一个词顶替另一个词，被顶替者沉入杠下，新词穿越杠线进入意义——锤子落下，意义瞬间生成。「他是头狮子」：不说他勇敢、有力、随时会扑上来，用一个「狮子」顶替整串形容词。新词不是描述他，是替换他；替换的瞬间，意义生成。

```
               聚合轴（垂直：替换）── 隐喻：一锤子换名字
                    狮子
                      ↑
          他  是 [        ] 的人
                      ↓
                  勇敢的人
          ──────────────────────────→ 组合轴（水平：拼接）
                         换喻：顺着链滑，永不到站
```

隐喻发生在垂直的聚合轴上：槽位里的词被顶替，意义一锤定音；换喻发生在水平的组合轴上：意义顺着链一格格滑走，永不到站。这两个方向，就是意义「动」起来的全部方式。

换喻像火车沿线走：站站都过，站站都只是下一站的起点，永远到不了终点。火车不生成新意义，它坚持（insists）——拉康说意义是「坚持而非固持」（"insisting, rather than consisting"）。「再刷五分钟」就是换喻的日常版：五分钟过去，还有下一条，永远差一站。五分钟不是终点，只是下一段的起点，而每一站都说服你继续。换喻还有一种常见形态：部分代全体（pars pro toto）——「白宫宣布」说的不是那栋楼，是整座美国政府；用相邻的部分指认整体，而整体永远不在场。

拉康在《无意识中字母的动因》的收尾段写下两个对子（Fink 英译《Écrits》p.439）：「症状是隐喻」「欲望是换喻」（"the symptom is a metaphor" / "desire is a metonymy"）。症状是隐喻——这个对子后面某篇会展开；欲望（désir / desire，那个永远「还差一点」的东西）是换喻——意思是：欲望不是一样东西，而是顺着能指链滑、永远差一站的那个「再往前一点」。

## 收尾：意义滑到哪去

这期的四块砖：一，能指在先，所指是效果——同一个词换语境就变味（「你真行」）；二，语言是链，意义不在词里，在位置关系里（「随便」）；三，无意识像语言——梦、口误、症状按替换与拼接的语法组织（口误）；四，这套语法有两根轴——隐喻一锤子换名字，换喻顺着链滑（「他是头狮子」「再刷五分钟」）。把砖块放回开头的问题：怪梦不是待解的密电码，而是一篇用替换和拼接写成的文本——只是它的语法，我们才认识了一半。

但问题还悬着：既然意义在链上滑，它到底在哪停下？你发出一句话，意思要到哪个瞬间才算落定？要回答这个，得先认识链上的两个「人」：说话的那个「我」，和听话的那位「他者」。这两个都不好惹：前者并不像你以为的那样在说话，后者也不像你以为的那样是个人。
