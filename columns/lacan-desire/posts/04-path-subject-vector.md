# 路径二：主体矢线 ΔS（欲望怎么走）

上篇我们把镜头停在缝合点上：意义在句尾才被钉住，钉钉子的是大他者。但还留着一个没说的事——能指链根本没法自己按住自己，它是在两个点上被另一条路穿过的。现在就走这条路。它从图的左上角出发，起点站着一块还没介绍过的记号：△。

## 向量 ΔS 与双重交叉

褚孝泉译《拉康选集》里，Graphe 1 评注段（《论主体的倾覆和在弗洛伊德无意识中的欲望的辩证法》）这样写：

> 「意义连环是被看作由向量 S·S' 所承载……在这个逆向上产生了与向量 ΔS 的双重交叉。只有在这后一个向量上我们看到了逮住的鱼儿。」

褚译的「向量」就是图上那条马蹄形矢线：从左上角出发，向下穿过能指链一次，折上大他者（A，能指的宝库、整个象征秩序，篇 2 那位；不是具体的人），再从 A 落回链尾。穿过链，正好两次。这两处交叉在研讨班第六期首讲（1958 年 11 月 12 日）里有名字：第一处在左，是「与代码相遇的点」；第二处在右，是「讯息产生之点」——也就是上篇的缝合点 s(A)，意义被钉住的地方。

```
              △（前语言的需要）
               \
                \          A（大他者）
                 \        /   \
                  \      /       \
                   \    /           \
   S ---------------×-----------------×---> S′
                  ①code            ②s(A)
```

① 是矢线第一次穿过链（代码点），② 是第二次（讯息点，即缝合点 s(A)）。矢线在链上方拱起一道弧，两次落点都在链上——这就是「双重交叉」。

「逮住的鱼儿」是读这张图最要紧的一句。把能指链想成一条河：词像水一样在河里流，可鱼——欲望——不活在河水里。词里翻不出欲望：一句「我爱你」里没有爱，只有三个字的位置关系。欲望在矢线上才现形——它不在「说了什么」里，在「这句话是谁、站在什么位置、想要什么」里。你发一条精心措辞的消息，写了又删、删了又写：那个「怎么写都不对」的劲儿不在任何一句话里，就在句子旁边那条看不见的线上。

也正因为如此，读任何一句话都得追问一句：谁在说、站在什么位置说？同一句台词，从被告嘴里说出来和从法官嘴里说出来，欲望完全不同——词是一样的，变的是矢线。所以拉康说「逆向」：篇 3 的意义顺着链走（S→S′），欲望却逆着方向、从链的外面来。① 处，需要被翻译成能指；② 处，说出来的意义被大他者钉住。链负责把话说完，矢线负责问：这句话是替谁说的？

## △ → $：穿过能指的隘口

矢线从 △ 出发。△ 是拉康给「还没被语言碰到的人」画的记号：前语言的、沉默的需要主体——他还没开口，还不会说话，只是一团纯粹的需要（besoin，need：血糖低了、胃空了）。注意这是拉康事后倒推的神话性起点，不是人类学考古：先把「没被语言污染的人」单独拎出来，看看语言加上去之后能变出什么。

从 △ 到 $（划杠主体，篇 2 那个被语言切开一道口的「我」），中间只有一件事：穿过能指的隘口（defile）。隘口本意是两山之间只容一人通过的窄道；拉康在研讨班第六期首讲画这个图时说，孩子很早就得学会——要让需要得到满足，必须低头穿过这个隘口。窄道的意思是：需要不能原样通过，它必须变形，被组织进能指。穿过之前，需要是纯粹的；穿过之后，主体被划上一杠，成了 $。

任何一句话都会背叛你，道理就埋在这个隘口里。你想「表达自我」，出口的却是语言表达它自己——词有词的位置，句子有句子的规矩，「你」只能按语言允许的方式出现。你永远说不出「完整的我」：一开口，出来的已经是能指加工过的版本。△ 想原样通过，隘口不让。

婴儿的哭声也一样：那还不是语言，但妈妈已经在问了——「饿了吗？不舒服吗？」哭声落到大他者那里，立刻被当作能指来听，立刻有了意义。需要自己说不出自己，它只能以变形的方式被说出。这就是为什么说 △ 是神话性的起点：你永远找不到一个「纯粹需要」的现场，找到的全是已经穿过隘口的版本。

## 需要 → 要求 → 欲望：d 住在撕开的缝里

过了隘口，矢线上依次站着篇 2 的另外两位。要求（demande，demand）记作 D——用语言向大他者索要东西的动作；欲望（désir，desire）记作 d。三者接成一条链：需要是沉默的（△ 层面）；一开口，需要就被翻译成要求——对爱的无条件要求，奶瓶塞过去孩子还闹，他要的是「奶被笑着递过来」；要求里永远多出来的那一截，就是欲望。

d 写在图上哪个位置？不在链上，不在 D 上，而在 D 与 △ 之间那道缝里。拉康的原话（法文版《Écrits》p.814，逐字）：

> 欲望在要求从需要撕裂开的边缘涌现（Le désir s'ébauche dans la marge où la demande se déchire du besoin）。

注意「撕开」：要求像一块布盖在需要上，永远盖不严，边缘露着缝——欲望就住在这道缝里。紧接着那句更悖谬：正因欲望被言说，它才不可被言说。

```
        △   需要：沉默，没有意义
        |
        |     开口说出 → 需要变味
        |
        d   欲望：住在撕开的那道缝里
        |
        D   要求：对爱的无条件要求
```

所以欲望天生缺一个对象。拉康在《无意识中文字的动因》（1957）收尾段断言：欲望是换喻——褚孝泉译本作「欲望确是个换喻」（《拉康选集》p.608）。换喻是篇 1 的火车：沿线一站一站走，永远到不了终点。你追一个又一个目标——那双鞋、那台机器、那张票——买到三天后，心已经不在了。不是你不会珍惜，而是「追到」这个动作本身把「那个」推去了下一站：你以为目标是钩子，其实是「差一点」在钩你。

再补一句更扎心的：要求的满足，恰恰证明它满足的不是欲望。「我要那个玩具」——玩具到手，欲望立刻搬家，住进下一个「我要」。不是因为人贪，而是因为欲望的结构就是换喻：它只住在「下一站」这个位置上。任何到手的东西都只是上一站的替身，欲望本身永远不落座。

## 欲望经幻象回应：$◇a

那「差一点」到底差在哪儿？拉康的回答很极端：它不是一个东西。这就是客体小 a（objet petit a / objet (petit) a，法语「小客体 a」；拉康坚持不翻译，让它保持代数符号的地位）——欲望的客体成因（object-cause of desire）：不是欲望瞄准的目标，而是启动欲望的东西。它是象征构成中丧失后复现的不可压抑剩余：先有洞，才有「我曾经失去过它」的故事。所以客体小 a 是个箩筐，不是东西——冰墩墩、豪车、漂亮衣服都能占据它，箩筐本身是空的。

这个「不是东西的东西」有几个名字：乳房、粪便、目光、嗓音、菲勒斯（phallus，象征能指，不是解剖器官）。有的清单还加一项「空无」，厌食症就是以「空无」为成因的临床例；两说并存。注意这些名字指向同一个结构：与主体分离的部分。

可人也撑不住一直悬着，于是给欲望搭了一个剧本——「如果我被所有人爱……」「如果我成功……」「如果我____，我就踏实了」。这个剧本就是幻象（fantasme / fantasy）。拉康把它写成公式：$◇a——左边是被语言劈开、答不出「你想要什么」的划杠主体 $，右边是空的箩筐 a，中间的 ◇ 读作 poinçon（法语「锥凿」）：把 $ 与 a 焊在一起，又让它们永远对不上——包含与不可能同时成立。幻象不满足欲望，它让欲望不崩溃。

```
         ◇（poinçon：锥凿）
        / \
       $   a
        \ /
   结合却不可能：不可满足，不是占有
```

拿张纸做练习：填「只要我____，我就踏实了」。填完问自己：你填的是东西，还是位置？大概率是位置——一个可以不断换布景、却动不了剧本的位置。「追到手就换」不是意志薄弱，而是结构命运：每个目标都是同一个剧本的新布景。

幻象有三件正事。第一，建构欲望：没有剧本，你连「想要」的姿态都摆不出来——欲望不是先在的燃料，而是在剧本里被组织起来的。第二，结构现实：你眼中的现实并不中性，职场、爱情、人生进度，都是按你的剧本裁剪出来的。第三，遮蔽裂缝：象征秩序内部有缝，幻象的工作就是一次次用「如果……就……」把缝糊上；糊上还会裂开，于是你换目标、换剧本。分析要做的不是实现欲望，而是走到幻象背面，认出剧本是剧本——这一步叫「穿越幻象」，系列的后面会回来收这笔账。

## 小结

这一篇走完了路径二：马蹄形矢线 ΔS 从 △（前语言的需要）出发，穿过能指的隘口——需要被划上一杠，成了 $；矢线上依次写着 D（要求）与 d（欲望，住在需要和要求撕开的那道缝里，永远差一点）；欲望没有对象，只有成因客体小 a，它经幻象 $◇a 获得回应。褚译那句「只有在这后一个向量上我们看到了逮住的鱼儿」：鱼不在词里，在矢线上。

矢线还没走完。它折上大他者 A 的时候，被一个问题挡住了——大他者不回答，它反手把问题抛了回来：「你想要什么？」下一站，我们走那条把主体圈起来的回路。
