# 驱力、语音召唤与代码：禁了享乐，人为什么还在绕圈

上一站我们走到图的顶端：享乐（jouissance，第 5 篇那个「再多一点，哪怕过头」）被禁，能指在享乐的位置缺席，图顶点不是满足，而是失败。可你低头看看自己：嘴上说「够了」，手指还在刷。如果享乐真的被禁了，这个停不下来的绕圈，是谁在绕？绕圈的从来不是欲望，是驱力——它写在图上最不起眼、却最致命的位置：代码（code）的位置。

## 驱力：想要 vs 绕圈

先说清驱力（pulsion / drive）。它是弗洛伊德的老词（Trieb），中文旧译「冲动」。它和欲望差在哪？欲望（désir）是「想要但得不到」：它有方向，指着那个永远差一点的目标——第 3 篇说过，欲望是换喻，顺着句子一路滑下去，永远到不了。驱力不是。驱力是「身体被某种声音、某种节奏拖着走」：它没有目标点，只有回路。欲望会问「我想要什么」；驱力不问，它只是绕。

最日常的例子是深夜刷手机。你已经「不想看了」，手指还在上滑。嘴上说「够了」，手不听。因为有个声音在说「还不够」——那是超我（superego），弗洛伊德说它是父母之声内化成的命令机器（《自我与本我》，1923）。拉康把这场遭遇说得更狠：语言主体与内化的超我之声——作越来越严苛、不可能的诉求——之间的相遇，是创伤性的、无面孔的。那个「还不够」不来自任何一张脸，它没有面孔，可它就在你耳朵里。拉康给这个位置留下了一句简短的原话：驱力是「要求中主体消隐后剩下的东西」（pulsion：ce qui advient de la demande quand le sujet s'y évanouit，《论主体的倾覆…》法文版 p.817）。注意措辞：不是「需要变成驱力」，而是驱力从要求里冒出来——主体在要求这条链上走到消隐（évanouit），剩下的那个绕圈的东西。

图上的写法是 $◇D：划杠主体（$，被杠穿的主体）与要求（D / demande，开口要东西的那个动作）用锥凿符号（◇）扣在一起——和幻象公式 $◇a 用的是同一个 ◇，那个「包含与不可能」的符号。第 2 篇的 $，第 3 篇的 D，在这里碰头。

但位置才是关键。拉康自下而上用四个阶段搭这张图：

```
    阶段4  驱力 / 阉割 / 享乐        $◇D   ← 写在最上层“代码的位置”
      ▲
      │
    阶段3  「Che vuoi?」与幻象      $◇a
      ▲
      │
    阶段2   镜像—想象层            I(A) / m / i(a)
      ▲
      │
    阶段1   基本单元              S→S′ / s(A) / A / $
```

注意：四个阶段是按教学顺序搭的，图始终作为整体存在，中间阶段只是搭楼用的脚手架。而 $◇D 的位置，属于阶段 4——最上层，与阉割、享乐、S(Ⱥ)（大他者缺的那个词）住在同一层。这一点我们专门核对过：英文拉康派百科 No Subject、Wikipedia、Soler、Eidelsztein 的讲法一致，$◇D 不在第二层。有些二手讲解把它画在第二层，与这些来源相悖——本系列以四阶段为准。为什么位置这么要紧？因为绕圈这件事不在图的基层，而在离享乐最近的地方——正因为「满足的终点」被禁掉了，剩下的才是一个没有终点的回路。

那么，驱力绕着转的那个对象，是什么？图上，它紧贴着一个词：代码。

## 代码：不是密码本，是词库＋规则

「代码（code）」在拉康这儿有两副面孔，先别混。

第一副是贬义的。拉康说，代码是动物交流的领域：动物信号是固定的一对一——一个信号，一个意思。人类语言恰恰没有这种关系：同一个词换个句子就变味（「你真行」是夸奖还是嘲讽？）。所以代码缺少人类语言的根本特征：歧义与模棱两可。把语言当成代码，是拉康要拆掉的通信模型。

第二副是中性、图上的用法。1958–59 年的研讨班（Seminar VI）讲解图的基本单元时，拉康把图上一点标为 code，同时称其为大他者的位置、「能指的电池」。这个用法里，代码 ≈ 语言——主体可用的能指全集。此时它指的不是密码本，而是「词库＋规则」：你开口用的所有词、所有语法、所有可能的句子组合，都在这个库里。

关键的话在这里（拉康语，出自《Écrits·论主体的倾覆…》Graphe 1 的评注段，法文版 pp.806–807——注意不是研讨班讲稿；英译经 De Assis《Logic of Experimentation》转引）：

> 「主体由代码构成，这意味着，连他自己发出的讯息，也是从大他者那里接收的。」
> （since it is from this code that the subject is constituted, which means that it is from the Other that the subject receives even the message that he emits）

这句话值得停下来读三遍。它说：代码不是中性的工具——用完放回抽屉那种。它是构成层。你以为你在表达「自己的想法」，可你的想法必须借词库的句子才存在；连「我自己想说的话」这句话本身，都是词库给的。发朋友圈的时候最明显：你精心挑选措辞、表情、梗，删了重写，改来改去，换的仍是词库里已有的组合。你以为在表达自己，其实是词库借你，把自己说了一遍。

所以这里要严格区分一对概念：大他者（A）≠ 代码。大他者是能指的宝库——一个位置，一个你永远可以从中借词的地方；代码是词库＋规则本身——主体被构成的方式。宝库是地点，代码是构成层。把 A 直接说成代码，是把位置和运作混为一谈。

还有一处细节（法文资料，置信度中等）：主体在陈述活动线上会遭遇「双重代码之位置」（lieu du code redoublé）——它标示主体自己所不知道的东西。也就是说，代码底下还叠着一层代码，你的话在两层编码之间生成，而你不必知道第二层。这正好呼应第 2 篇那句「句号不是说话的人打的」。

而驱力公式 $◇D，就写在代码的位置上。法文资料这样表述：在代码的点上，$◇D 把主体在幻象中的消隐（eclipse）时刻，与一种口、肛、窥视或召唤性的要求相联结。注意最后一个词：召唤性（invocatory）。绕圈的回路，有一头直接通向「语音召唤」。这就是下一节。

## 语音召唤：被喊到名字之前

语音召唤（pulsion invocante / invocatory drive）是拉康在 1964 年 3 月的研讨班——Seminar XI《精神分析的四个基本概念》——正式命名的。它的对象是语音（la voix），与耳朵相连；拉康说它「最接近无意识的经验」，邻近死亡驱力。1964 年 3 月的驱力诸讲里，有一句完整的话（法文版《四概念》p.96，拉康回应萨福安提问时说的）：「在观看层面，我们已经不在要求的层面，而在欲望、在大他者的欲望的层面；召唤性驱力亦然，它最接近无意识的经验。」

但这个词不是凭空造出来的，它有一条长长的前史。拉康自己把三个画面排在一起。

第一个画面：fort-da。弗洛伊德的孙子把线轴抛出去，「fort！」（没了）——再拉回来，「da！」（回来了）。拉康注意到这个游戏的咒歌式特征：孩子口中那些「会唱歌的音素词」，先于任何意义，已经是一个语音回路。抛出去、拉回来，消失、在场——绕圈的原型，而且它绕的是声音。

第二个画面：shofar，公羊角号。Seminar X《L'Angoisse》（1962–63；1963 年 5 月 22 日那一讲，Seuil 2004 pp.283–298）里，拉康讲摩西携法版归来——号角吹响，法降临了。他引雷克（Theodor Reik）的话：shofar 说到底不是别的，「是上帝的声音、雅赫维的声音」；又点破它的位置——「弑父及它所统摄的一切」，就在号声里回响，原初欲望正是在那里「作为禁止、作为不可逾越」被构成（STA-F 讲稿逐字）。注意：前一句「弑父」是逐字原文；后一句常被概括成「象征界的来临」——那是评述的转述，不是原话。一个词都没有，但那个声音让整个共同体站住了：语音召唤不必是言语。

第三个画面：蒙克《呐喊》。拉康评注过这幅画。画中人捂着耳朵、张着嘴——无声的呐喊。被声音淹没、却喊不出声：这正是「被召唤、却还不会召唤」的姿势。三幅画连起来是一条线：声音先于意义，召唤先于说话。

「被喊到名字」为什么构成你？做个最简单的实验：点名。教室里老师喊「张三」，你应声——那个应声的「是」，不是你想好了才说的。在你来得及想「我是谁」之前，一个声音已经占住了一个位置，你应了。你以为你是说话的人，其实在这之前，你早就是「被喊的那个人」。主体最先的形态不是说话者，而是被召唤者；能喊别人名字（成为召唤者），是后来的事。这也是为什么它被算作客体小 a 的一种形态——第 4 篇的五形态里，嗓音在列：它是意义被减除后残留的声学维度，不属于语言，却撑起了语言。

## 语音在图上：下层链的终点

现在回到图。完整图的下层链，终点不是「意思」，是语音：

```
    [上层]  Jouissance ─────────► Castration（阉割）
                                        │
                                        │  ← 同一侧（法文版 Écrits p.817）
                                        ▼
    [下层]  Signifier ───────────► Voice（语音）
           （能指→语音，意识/陈述层）
```

两条链结构完全相同——第 1 篇说过的 duplication：上层「享乐→阉割」，下层「能指→语音」。注意右端对齐：上层链的终点是阉割，下层链的终点是语音，拉康把语音与阉割放在图的同一侧（法文版《Écrits》p.817）。这不是偶然的对称：语音是能指链走到头的残余，它站的位置，正对着享乐被划杠的位置。换句话说，绕圈绕到最后剩下的那个东西——声音——恰好守在享乐被禁的切口旁边。声音是主体与享乐最贴近的残余。

这里要交代一个查证边界：「invocation」这个字样，并没有作为独立节点被直接标注在图上——我们没有找到权威图文来源证明图上写着它，这一点上学者间有分歧，本系列不采纳「图上标有 invocation」的说法。我们按有据的链条写作：语音＝下层链的终点＋召唤性驱力（1964 年命名）的对象＋与阉割同在图的同一侧（p.817）＋$◇D 在代码位置联结召唤性的要求。宁可少写，不写错。

最后还有一个概念：point sourd，聋点。拉康说，主体必须「忘记自己是原始音色的接收者」——对原初之声变得聋（一种结构性的耳聋，经由原初压抑完成）——才能反过来成为召唤者。换句话说：你要先学会「没听见」那个最初的声音，才轮到你开口喊别人。失败者则被大他者之声侵占——精神症临床里，有人把耳朵贴向晶体管收音机，试图用噪音盖过「那些声音」（此段细节来自单一来源群——法文 pulsion 专题文献，置信度中等，供参考）。

至此三块拼图到位：$◇D 在最上层的代码位置；代码是借给你一切语言的词库＋规则；语音召唤是被喊到名字之前你就已经在的位置。驱力绕的那个圈，绕的就是语音这个对象——而这一切，和阉割同侧。

## 小结

这一篇回答三个问题。一，驱力和欲望差在哪：欲望有方向、永远差一点；驱力没有终点、只有回路；公式 $◇D 写在最上层的代码位置——不在第二层（No Subject / Wikipedia / Soler / Eidelsztein 一致的四阶段查证结论）。二，「代码」是什么意思：不是密码本，是词库＋规则（≈语言＝能指全集）；主体由代码构成，连自己发出的讯息也是从大他者处接收的；大他者是宝库（位置），代码是构成层，两者不等。三，「被喊到名字」为什么构成你：1964 年 Seminar XI 正式命名语音召唤；你是先被召唤的，然后才成为说话的人；语音是下层链的终点，与阉割在图同侧（法文版《Écrits》p.817）。

零件齐了。能指链、缝合点、划杠主体、要求、幻象、客体小 a、享乐、匮乏的能指、驱力、代码、语音——整张图的每一层都立起来了。那么只剩最后一个问题：把整张图拼起来看，它到底讲了什么？
