# 完整图合读与批判延伸：一张图，三场争论

现在，我们终于可以把这张图完整地摆上桌了。上一站零件齐了，但零件堆在一起不是图。这一篇做三件事：把整图合读三遍；看中文世界怎么读它——一场绕不开的翻译之争；再问：经历后期转向、德勒兹的进攻、Fink 与 Žižek 之争，这张图过时了吗？

## 完整图合读：两链怎么咬合

先认全貌。完整图是两条平行叠置的链：下层「能指→语音」，属陈述层（statement / énoncé）——说出来的话本身；上层「享乐→阉割」，属陈述活动层（enunciation / énonciation）——「正在说这句话」这件事，无意识那一层。两层结构完全相同（duplication）。一条马蹄形的矢线从左上垂到左下，穿过两条链：

```
        △ 纯粹需要的主体（进链之前）
         \
          \           [上层链] 无意识 · 陈述活动层
           \          双重铭刻：下层的无意识回响
            ×──── 享乐（S(Ⱥ) 缺位之词所在）──▶ 阉割
           /  \                                    │
          /    \                          $◇D（驱力，写在代码位置）
         /      \                                   │
        /        \                                  │
       /          d（欲望）── $◇a（幻象）───◇─────┘
      /
      │            [下层链] 意识 · 陈述层
      ×──── 能指 S ──▶ s(A)（缝合点）──────▶ 语音
      │                                         │
      │                                 I(A) m i(a)
      │                                         │
      ▼                                         ▼
   $（划杠主体）                          A（大他者）
```

示意图，不是临摹——但该在的位置都在：$◇D 在最上层。路数清了，下面沿图走三遍。

## 先数清楚：图上有几条路

走图之前，先把路数清楚——按拉康自己的原话（《论主体的倾覆…》Graphe 1 评注段，褚译）：「意义连环是被看作由向量 S·S' 所承载……在这个逆向上产生了与向量 ΔS 的双重交叉。只有在这后一个向量上我们看到了逮住的鱼儿。」图上有两条链、三条路：

**路一：能指链 S→S′（下层横线）。** 陈述层——你说出口的那句话本身。它是被穿过的路，自己不主动走；方向从左到右，意义事后（après-coup）才落定（第 2 篇那个句号）。

**路二：主体的马蹄形矢线（向量 ΔS）。** 从 △/$ 出发，向右下穿过能指链（第一处交叉），折上大他者 A，再从 A 落回链尾（第二处交叉，s(A) 讯息点）——这就是「双重交叉」。褚译那句「只有在这后一个向量上我们看到了逮住的鱼儿」：欲望不活在链上，活在这条矢线上。

**路三：屈从圆圈 s(A)→A→s(A)。** 路二的后半截单独收成环：「主体对能指的屈从产生在从 s(A) 到 A 随后又从 A 回到 s(A) 的路程中的。这个屈从是一个圆圈。」——第 3 篇的「需求的环形地狱」就是它。

**路四：上层链 享乐→阉割。** 完整图上层的矢量链（Jouissance → S(Ⱥ) → $◇D → Castration），图式 3 时叠加的「被叠加的那一层」（étage surimposé），与下层结构完全相同（双重复制）：你在陈述层说「够了」，陈述活动层里驱力还在绕（第 5、6 篇）。

**路五：镜像路 i(a)→m（头顶压着 I(A)）。** 图式 2 加的想象层矢量：从镜子里的形象（i(a)）到自我（m），再被自我理想 I(A) 锚定——第 2 篇那张「盖缝的画面」。

驱力 $◇D 不另算一条路，它是路四上的一个绕圈点（写在代码的位置）。五条路里，路一、路四上下对称，路二穿过它们，路三圈住主体，路五贴着镜像层——传动关系一目了然。

**第一遍，自下而上——拉康搭楼的方式。** 阶段一，基本单元：能指链 S→S′ 与矢线相交于 s(A)，意义被大他者「事后」钉住（第 2 篇的句号）；阶段二，镜像层：自我 m、形象 i(a)、自我理想 I(A)；阶段三，「Che vuoi?」与幻象：大他者把问题抛回给你，欲望 d 经幻象 $◇a 回应；阶段四，驱力、阉割、享乐与 S(Ⱥ)：$◇D 写在代码位置，顶端是缺位的词与被禁的享乐（第 5、6 篇）。但要记住：四阶段是教学装置，不是时间演化——图始终作为整体存在（拉康原话：这不是「阶段」，是「每个图式相对于后一个图式的逻辑在先性」，Seminar VI 首讲，1958 年 11 月 12 日）。

**第二遍，自上而下——上层是下层的无意识回响。** 这是双重铭刻（double inscription）的几何化：同一句话同时载两层意义——下层说「我能行」，上层在说「我要你看见我」；嘴上说「够了」，驱力还在绕。上层「享乐→阉割」正是下层「能指→语音」的回声：每个句子同时是「一句话」和「一个欲望在陈述活动层发生的事」。

**第三遍，从左往右——主体的生成。** △（进链前的纯粹需要，第 3 篇那个沉默的啼哭）穿过「能指的隘口」被划杠成 $；$ 开口要，要求转译成爱的证明；要求与需要之间的缝隙里欲望 d 涌现；d 经幻象 $◇a 得到一个位置；最后 $◇D 在最上层把一切拖进绕圈的回路。从左往右，就是从「还没进入语言的存在」读到「被语言组织完毕、还在绕圈的存在」。

三遍走完，拉康自己的一句话可以落地。他在文中交代图的用途（褚孝泉译《拉康选集》图式 1 的说明）：图用来「标明相对由能指在其陈述中规定的主体而言，欲望的位置在哪里」；同时区分三样常被混为一谈的东西：被压抑者（le refoulé）、欲望（le désir）与无意识（l'inconscient）——三者不是一回事。这就是整图的叙事：欲望没有被回答，它被定位了。

## 中文接受史：吴琼与褚译本之争

中文读者读这张图，绕不开两个人。第一个是吴琼。他的《雅克·拉康：阅读你的症状》（2011 年人大版，2024 年修订）第十章第三节「欲望图」，是中文世界最重要的讲解文本。吴琼的形容很有名：1960 年那篇文本是《文集》中「最为艰涩难懂的一个文本」——理论构件按循环往返的拓扑逻辑叠进四个图形，形成「巴洛克式的七宝楼台」，一般研究者「采取回避（绕行）的方式」，吴琼自称「贸然想要去做一次攀爬」。四图两链叠在一起，确实像一座绕行的楼——六篇拆完，你已经在爬楼了。

第二个是褚孝泉。他译的《拉康选集》（上海三联书店 2001）收有欲望图所在的那篇《论主体的倾覆……》，中文读者读它基本都经由褚译本。但这也是最有争议的译本：2006 年马元龙在《翻译需要敬畏之心（下）》（《博览群书》2006 年第 12 期）里称它是「一本非常令人失望的译著」，最著名的两条是：phallus 译作「男根」——应为音译「菲勒斯」，它是「纯粹的能指，一个没有所指的能指」，与生物学的阴茎（penis）不可混；以及第一人称 je 被误译成复数「我们」。褚孝泉在《关于〈拉康选集〉的翻译问题》中回应：「我们」之争里，马元龙抄录的原文实为第一人称复数 nous（英译本用 I 误导了他），法文惯用 nous 自指；「男根」与「阴茎」的区分正是斟酌再三的结果——他批评马元龙凭英译本评判中译文，而非以法语原文为依据。论争没有官方胜负，它塑造的是语境本身：从此中文读者手里拿的是褚译，心里装的是围绕它的批评与纠错。

译名也随之不统一：graphe du désir 有「欲望图」（吴琼及学界多数）、「欲望图式」（周文莲，《世界哲学》2019 年第 1 期）、「欲望图解」「欲望图示」「欲望图表」等写法，褚译本作「图式」。严格说，拉康的 schéma（如 L 图式）才对应「图式」，graphe 更近「图/图解」。本系列以「欲望图」为准——不是仲裁，是约定。

## 图过时了吗：后期转向

轨迹：1972–73 年的研讨班 XX《Encore》起，享乐获得「非全」（pas-tout）逻辑——否定不再来自禁令，而来自集合自身的逻辑；1974–75 年的 XXII《RSI》起，实在界经由博罗米结（nœud borroméen）展开——三界成为相互独立又互锁的三个环；1975–76 年的 XXIII《Le sinthome》再加第四环 sinthome（圣状/症状），结要靠它维系。学术文献的表述是：欲望图所属的「面拓扑/图式阶段」连同莫比乌斯带、环面，被后期教学逐步取代（superseded），最终达至博罗米结。

但「取代为理论重心」不等于「宣布失效」——这是两句话。准确说法：后期拓扑让欲望图不再是理论顶点，拉康没说它错了；图与结回答的是不同层次的问题：

| | 欲望图（1960 年代） | 博罗米结（1970 年代中起） |
|---|---|---|
| 问题 | 意义与欲望如何在能指链上缝合、定位 | 三界与享乐如何在实在中纽结、维系 |
| 落点 | 主体在话里的位置 | 主体在结构中的存在方式 |

所以「过时了吗」的答法不是「是/否」，是「换了重心」：图没有作废——否则 Žižek 一脉不会拿它去做意识形态批判——但理论兴趣从「意义如何缝合」移向了「三界如何互扣」。

## 德勒兹的进攻：欲望是匮乏还是生产

第三场争论来自图的外面：德勒兹（Gilles Deleuze）与瓜塔里（Félix Guattari）1972 年的《反俄狄浦斯》（L'Anti-Œdipe）。先看清它打在哪个部位。

拉康式欲望的底座是匮乏（manque / lack）：主体因语言被划杠（$），欲望因缺失而起，规则因禁令而立。德勒兹和瓜塔里拒绝这个底座：欲望不是匮乏，是生产——欲望是机器（machine désirante），「欲望的秩序即生产的秩序」；加塔里称拉康的能指是「专制能指」（despotic signifier）。最有名的反转是《反俄狄浦斯》对禁令的拆解：

> 「律法说：你将不娶你母亲、不杀你父亲。我们这些顺从的主体心想：原来这就是我想要的！」

读出来了吗？先有禁止，欲望才被生产出来——不是「欲望先存在、律法镇压它」，而是律法划出禁区的那一刻，「想要」才诞生。这正是《论主体的倾覆…》里的逻辑，德勒兹却把矛头反过来：你把欲望画成匮乏，等于把它钉死在律法的影子里。本系列的定性：德勒兹不是批这张图画得不对——《反俄狄浦斯》没有针对图形细节逐条开火——他批的是它把欲望画成了匮乏：攻击在概念层，图只是被殃及的装置。

两人还留下一段互评（二手传记/访谈，置信度中等）：拉康曾赞德勒兹「我所需要的正是像你这样的人」（据贝克曼《吉尔·德勒兹》传记转述）；德勒兹与瓜塔里在访谈中回敬「我们正是以精神分裂的方式帮助他」。

## Fink vs Žižek：临床读法 vs 意识形态挪用

最后一组对照发生在图的「使用者」之间：布鲁斯·芬克（Bruce Fink）与斯拉沃热·齐泽克（Slavoj Žižek）。芬克是拉康的主要英译者，读法译者式、临床、忠实文本——他甚至曾称《论主体的倾覆…》「不可读」（评述文献转引）；齐泽克则用黑格尔—马克思的框架把图扛去做文化批判。最著名的挪用是《意识形态的崇高客体》（The Sublime Object of Ideology, 1989）：图上的缝合点（point de capiton，本系列第 2 篇的 s(A)）被读成意识形态缝合——一个主人能指（比如「共产主义」）回溯性地定住自由、国家、正义这些漂浮能指的意义，还抹去自己的痕迹，制造「意义本就在那里」的错觉。同一张图：芬克在分析室里用它读病人的话，齐泽克在讲座上用它读意识形态。

两条路线之间，有四个可以对照的落点（据 Sokolofsky 等人的批评整理）：

| 落点 | Fink 一侧 | Žižek 一侧 |
|---|---|---|
| 女性享乐 | 女性快感虽涉「实在」仍可被照亮（D'Amore 文对照两种立场） | 强调其越出能指、近乎不可言说 |
| 实在界的定义 | 「实在界……不存在」（the real… does not exist） | 同时必然又不可能的实体 |
| 主体的拓扑 | 莫比乌斯带——自我与无意识两面互扭 | 被现实/幻象掩蔽的「被排除的内核」 |
| $◇D 与 sinthome | Sokolofsky 细读 XXIII：$◇D 是象征与实在交叉处的菲勒斯享乐 | 把 $◇D 与后期 sinthome 直接等同——Sokolofsky 指为误读 |

最后一行值得多说一句：齐泽克把 $◇D 读作 sinthome，被 Jake Sokolofsky 在《(Un)quilting the Quilting Point》中逐点批评。这里不必选边；值得记住的是，同一张图能被两种用法同时「用坏」与「用活」，说明它承载的不是答案，而是一套传动。

## 小结

合读三遍，整图讲一件事：欲望不被回答，只被定位——它在能指链上被构成、缝合、堵死、逃逸。中文世界读它绕不开吴琼与褚译本之争；它没有过时——后期结拓扑取代了图式阶段的重心地位，但未宣布失效；德勒兹批的不是图，是把欲望画成匮乏；Fink 与 Žižek 之争是临床忠实与意识形态挪用之争。

最后，把三件工具留给你做自检清单——这是全系列的落点。读任何意义系统（一段话、一部剧、一个热搜），问三件事：**它的缝合点在哪？**（什么词或时刻让意义突然落定）**它缺哪个词？**（说不出、绕开的缺位——S(Ⱥ) 的位置）**它遮住了什么？**（什么幻象在盖住不一致）。这三问就是「穿越幻象」（traversée du fantasme，第 4 篇预告的终点）的第一步——不是实现欲望，而是看清剧本。正如全系列反复说的：这张图不回答「你想要什么」，它回答「你为什么会要」。想继续走，还有三条路：穿越幻象、意识形态批判、博罗米结。
