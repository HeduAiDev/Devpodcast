# Che vuoi? 幻象与客体小 a：你给欲望搭的剧本

上一篇结束时，我们把一个问题留在了桌上：「为了被爱而成为的样子，真是你想要的吗？」你追着大他者（Autre / the Other——整个象征秩序，语言与法则的总和）问它想要什么，满心以为答案握在它手里。现在请坐稳：大他者不会回答你。它反手把问题抛了回来——Che vuoi?（意大利语，字面意思正是「你想要什么？」）。

这声质问听起来像审讯。而这一篇要拆三件事：为什么问题会被反抛回来？欲望到底有没有对象？以及——你靠什么撑住，才没有在对答案的等待中崩掉。

## 大他者想要什么：Che vuoi?

先回一趟上一站的地形。我们说「人的欲望是他者的欲望」（le désir de l'homme est le désir de l'Autre，《论主体的倾覆和在弗洛伊德无意识中的欲望的辩证法》，1960 年 Royaumont 报告，收入《Écrits》1966）——这个表述天生有两副面孔：既是我欲望大他者想要的东西，也是我困惑于「大他者想要我什么」。前一副面孔催生「成为它喜欢的样子」的努力，我们把它画成了自我理想 I(A)；后一副面孔才真正难缠：它逼你开口，向大他者发问——「你到底想要什么？」

这一问，就把你送进了困窘。因为大他者没有脸、没有表情、没有一句能当答案的话。它不是某个可以回答你的具体的人，而是一个位置：所有能说出的句子的总和，第 2 篇那个「能指宝库」。你向整片海洋要一条船，海洋沉默。更糟的是，你的问题在它那里转了一圈，又原样回到你嘴边。

拉康在讲到这一层时，特意注明「Che vuoi?」的出处：卡佐特（Cazotte）《痴情魔鬼》（Le Diable amoureux, 1772）中魔鬼之语。在那部小说里，主人公召唤出魔鬼，本要质询这位「他者」——魔鬼的回答却是一句反问：「你想要什么？」你以为你在审问它，其实你收到的是你自己讯息的颠倒形式。评述文献把这个机制概括为：主体从大他者处以反转形式接收自己的讯息，其例证正是 Che vuoi?。

在图上，这一层长这样（欲望图第三阶段的局部）：

```
        A（大他者：能指的宝库）
        │
        │  ① 主体发问：「你到底想要什么？」
        │
        │  ② 问题被反抛回来：Che vuoi?
        │
        v
      $◇a（幻象——回应之路径）
        │
        │  欲望 d（在要求撕开需要的边缘处涌现）
        │
        v
   D′ ───────── s(A) ───────── S′（下层链：意义在此缝合）
```

图右的 s(A) 是第 2 篇的缝合点：意义在这里才回溯性地落定——所以「你想要的到底是什么」这句问话，直到被回应的那一刻才算成形，而此刻它成形为一记反抛。主体回应这声质问有两条路：在欲望这一层，走的是幻象之路，形式化为 $◇a（本篇的主角）；在自我那一层，走的是形象之路 i(a)。讲幻象之前，得先把它的右边——客体小 a——说清楚。

## 欲望没有对象，只有成因：客体小 a

先做一个实验：回忆你上一次「非买不可」的东西——那双鞋、那台机器、那张票。买到之后呢？三天后它还在，你的心已经不在了。再买下一个，再来一遍。这个「之后呢？」的空洞不是东西的错，也不是你的错。它是欲望（désir / desire）的常态：欲望没有对象，只有滑动。

第 3 篇兑现过预告：欲望是换喻（《论文字》，The Instance of the Letter，1957，收尾段）——它像火车沿线一站一站走，永远到不了终点；每个「到站」都被证明不是「那个」。那么，「那个」到底存不存在？拉康的回答很极端：不存在。不是「存在但找不到」，而是它从来不是一个东西。这就是客体小 a（objet petit a / objet (petit) a，法语「小客体 a」；拉康坚持不翻译它，让它保持代数符号的地位）要说的第一件事。

学术地说：客体小 a 是欲望的客体成因（object-cause of desire）——不是欲望瞄准的目标，而是启动欲望的东西；它是「象征构成中丧失后复现的不可压抑剩余」。主体穿过能指的隘口（第 2 篇 $ 的出生证明）时，象征秩序从你身上削掉一块什么；这一块再也不会回来，但它留在结构里的空洞一直发动着你的欲望。注意这里的悖论：原初丧失的「什么」其实什么都不是——原初的丧失只是回溯性建构：先有洞，然后才有人往洞里填「我曾经失去过它」的故事。

所以客体小 a 是个箩筐，不是东西。冰墩墩可以占据它，豪车可以占据它，漂亮衣服可以占据它——占据它的东西永远在换，箩筐本身是空的。「你追一个又一个目标」这件事的结构，比任何目标本身更接近真相。把对象 a 当成某个具体事物，是入门者最常见的滑倒处。

顺带把它和第 2 篇的邻居分清楚。客体小 a ≠ 他者的形象 i(a)（image de l'autre，镜像中的同类之像）：

| | 他者的形象 i(a) | 客体小 a |
|---|---|---|
| 是什么 | 想象的「我的形象」，自恋投注的对象 | 象征构成丧失后的剩余，欲望的成因 |
| 在图上的位置 | 镜像层，与自我 m 对峙 | 幻象一侧 |
| 相当于 | 镜子里那个「像我的人」 | 「丢了什么东西」这件事本身 |

最后是形态清单。拉康给这个「不是东西的东西」列过名单：主流学术列表为五种——乳房、粪便、目光、嗓音、菲勒斯（phallus，象征能指，不是解剖学器官——翻译史上反复提醒过的坑）。部分晚期清单还附加一项「空无」（the nothing），厌食症就是以「空无」为客体 a 的临床例；两组列表在文献中并存，写作时需两说俱存。注意这些名字：目光不是「看」，嗓音不是「声音」，乳房不是「奶」——它们都是「与主体分离的部分」，是同一个丢失结构的五个名字。

## 幻象公式 $◇a：给欲望一个剧本

回到 Che vuoi?。大他者反抛「你想要什么」，你答不上来——不是答错，而是根本没有答案可答：欲望没有对象。那这声质问就悬在空中了吗？人想出了一个办法：编剧本。

「如果我被所有人爱……」「如果我成功……」「如果我的生活从那个决定之后完全不同……」填空处放的从来不是一件东西，而是一个完整的场景，你在场景里有一个确定的位置。这个剧本，就是幻象（fantasme / fantasy）。

拉康把它写成一个公式：$◇a。左边是划杠主体（$）——被语言劈开、答不出「你想要什么」的那一位；右边是客体小 a——那个空的箩筐；中间是 ◇（poinçon，法语「锥凿」）。◇ 这个符号很关键：它同时表达结合与分离、「包含与不可能」（both implication and impossibility）。意思是：幻象里，$ 与 a 既贴合在一起（剧本让你觉得「这就是我要的」），又永远对不上——幻象结构上不可满足。

```
         ◇（poinçon：锥凿）
        / \
       $   a
        \ /
   结合却不可能：不可满足，不是占有
```

注意：◇ 不是等号，不是箭头，更不是「拥有」。$ 不占有 a——幻象里没有「我得到了那个东西」这回事。它是把两者焊在一起的那道缝：越贴合，越不可能。「主体拥有客体 a」这种读法就此排除。

评述界的通行转述（No Subject「Graph of desire」条目）：人的欲望本质上不是固着于对象，而是固着于幻象。换喻实验里的每个目标，都是同一个剧本的不同版本：你买的是「成功者的我」这个角色，不是那个东西。剧本不变，布景常新。

做个练习，拿一张纸填两句：

- 「如果有一天所有人都\_\_\_\_，我就踏实了。」
- 「只要我\_\_\_\_，我就配得上我拥有的一切。」

填完问自己：你填的是一个东西，还是一个位置？大概率是位置——一个你可以不断挪动布景、却动不了剧本的位置。

## 幻象不满足欲望，它让欲望不崩溃

那么幻象是干什么用的？反直觉的回答是：它不是用来满足欲望的——它让欲望不崩溃。「以为幻象能满足欲望」是通行误读之一，真相正好相反。

幻象有三样正事。第一，建构欲望：没有剧本，你连「想要」的姿态都摆不出来——欲望不是先在的燃料，而是在剧本里被组织起来的。第二，结构现实：你眼中的现实并不中性——你看到的「职场」「爱情」「人生进度」，都是按你的剧本裁剪出来的。第三，遮蔽象征秩序的不一致：象征秩序内部有缝，大他者不是一个自洽的系统；幻象的工作，就是一次次用「如果……就……」把这条缝糊上：规则有漏洞没关系，只要我做到 X，一切就说得通。

问题在于：一次次遮盖终将失败。「如果……就踏实了」的 X 永远兑现不了——不是因为你不努力，而是因为那道缝是结构性的，糊上就会再裂开。于是你换剧本、换目标、换「只要我……」。这解释了为什么「追到手就换」不是意志薄弱，而是结构命运。

所以，分析的目标从来不是「实现欲望」。分析要让主体走到幻象的背面看一眼：这个剧本是编的，那个箩筐是空的，大他者抛回的问题没有标准答案。这个动作有一个专门的名字：穿越幻象（traversée du fantasme）——不是撕毁剧本（那只会换来一个更僵硬的剧本），而是认出剧本是剧本，从此不再被它牵着走。这也是本系列的最后落点，第 7 篇会回来收这笔账。

## 小结

这一篇回答了三件事。第一，「Che vuoi?」是大他者反抛的问题：你问大他者想要什么，它没有答案可给，问题以颠倒形式回到你嘴边（拉康自注出处：卡佐特《痴情魔鬼》，1772）。第二，欲望没有对象：客体小 a 是成因不是目标，是丧失后复现的不可压抑剩余，是空的箩筐——什么都能占据它，它本身不是东西。第三，幻象 $◇a 是你给自己搭的剧本：它不满足欲望，它让欲望不崩溃——建构欲望、结构现实、一次次遮盖象征秩序的裂缝，直到分析带你穿越它。

还剩最后一个问题，也是最重要的问题：幻象要遮盖的那道裂缝，到底在哪？谜底比你想的更扎心——它不在你这边。
