# 批判与延伸：这张图挨过的枪，和它的第二生命

[S1] 欢迎回来。欲望图系列最后一期，第九期。上一期我们把整张图摆上桌，五条路一起跑了一遍——图，讲完了。但结尾留了句话：「别人怎么说」，也是这张图的一部分。今天兑现这句话：这张图挨过的枪，和它的第二生命。[/S1]

[S1] 还是我们三个：阿凯，系列作者；阿哲，替读者来的。今天听完能答四个问题：中文世界怎么读这张图？图过时了吗？德勒兹批的到底是什么？同一张图，怎么被用成两样东西？[/S1]

[S3] 我先表个态。图我好不容易爬完了八期——今天要是告诉我白学了，我可不答应。[/S3]

[S2] 放心，不白学。——但你爬的这座楼，中文学界起过外号。吴琼，中国人民大学教授，他的《雅克·拉康：阅读你的症状》第十章有专节讲这张图。他的原话是——这个文本是《文集》里「最为艰涩难懂的一个文本」，理论构件叠成一座「巴洛克式的七宝楼台」，一般研究者绕着走，他自称「贸然想要去做一次攀爬」{{voice:voice-007}}——大意就是这么说的。[/S2]

[S3] 七宝楼台——这个词我得问问。什么叫七宝楼台？[/S3]

[S2] 简单来说——华丽、繁复、一层套一层，好看但找不到楼梯。四个图形叠在一起，理论零件按循环往返的逻辑装配，你不知道从哪进。——咱们前八期干的，就是给这座楼装楼梯：一条路、一条路地走。[/S2]

[S1] 这是第一座楼。第二座是译本。中文读者读这张图，手里拿的几乎都是褚孝泉译的《拉康选集》，二〇〇一年上海三联版，欲望图那篇就收在里面。而这个译本，吵过一架有名的。[/S1]

[S2] 我来说说这场架。二〇〇六年，马元龙在《博览群书》发文——《翻译需要敬畏之心》，称这是「一本非常令人失望的译著」{{voice:voice-009}}——原话的分量。最出名的一条：phallus 这个词，褚译作「男根」；马元龙说应该音译「菲勒斯」。[/S2]

[S3] 等等——男根、菲勒斯，不就是一个词怎么译的问题吗？值得专门写文章吵？[/S3]

[S2] 值得。——这不是换词，是换层。按「男根」读，你会把图上那个缺位词当成生物学器官——长在某处的东西。按「菲勒斯」读，它才是拉康要的：一个纯粹的能指，不指任何东西，只标示「缺位」本身。一个词译错，理解整个换一层。[/S2]

[S3] 我复述一下：译成「男根」，读者把它当器官；译成「菲勒斯」，它才是个只表示缺位的词。——所以哲学文本里，翻译不是小事。[/S3]

[S1] 那褚孝泉怎么回应？[/S1]

[S2] 他写了篇《关于〈拉康选集〉的翻译问题》回应，两条线。——第一，马元龙还批过：第一人称 je 被译成了「我们」。褚孝泉说，那句原文其实是 nous——法文惯用它自指，是英译本用了 I，把他误导了。第二，「男根」和「阴茎」的区分正是斟酌再三的结果。他反过来批评对方：拿英译本评判中译，不回法语原文{{voice:voice-009}}——两边主张大概如此。[/S2]

[S1] 让我来捋一下——这场架，有胜负吗？[/S1]

[S2] 没有官方胜负。它留下的是语境本身：中文读者手里拿的是褚译，心里装的是围绕它的批评和纠错。顺带一提，这张图的中文名都没统一——「欲望图」「欲望图式」「欲望图解」并存。法语里两个词本来就不一样：L 图、R 图那类才叫「图式」，这张图用的词更接近「图」或「图解」。咱们系列用「欲望图」——不是仲裁，是约定。[/S2]

[S3] 我能不能这么理解：名字都没统一，说明这张图在中文世界还没被「缝合」——还没有一颗钉子把意义钉住？[/S3]

[S1] 你这话我得记下来。——中文世界吵「怎么译」，英文世界骂得更狠。一九八八年，雷蒙德·塔利斯（Raymond Tallis），作家兼神经学家，出了本书，直译《不是索绪尔》——书名就冲着索绪尔来。他给拉康贴了个标签：linguistic charlatan——「语言学骗子」{{voice:voice-002}}。大意是：拉康对语言学的使用是「语言唯心主义」，脱离实在。[/S1]

[S3] 骗子——这帽子够大的。他凭什么？[/S3]

[S2] 他的靶子是拉康对索绪尔的挪用——第一期讲的能指翻转。但很多评论者指出，塔利斯打的是一个简化过的拉康{{voice:voice-002}}。而且有个事实挺尴尬：拉康后来自己也离开了索绪尔。——这就接到今天第二个问题：图，过时了吗？[/S2]

[S2] 变化来自拉康自己。三个时间点。——第一个，一九七二到七三年，研讨班第二十期：享乐——第七期那个「再多一点，哪怕过头」——有了新逻辑，法语叫 pas-tout，译作「非全」。否定不再来自禁令，而来自集合自身：不是「规则不许你全要」，是结构上根本凑不齐一个「全」。[/S2]

[S3] 等等——「凑不齐一个全」，这什么意思？[/S3]

[S2] 你以为享乐被禁，是有人举牌子说「不许」。新逻辑说：不是有人拦你，是「全」这个东西本身就不存在。——禁令是外面的墙，非全是里面的缺口。[/S2]

[S2] 第二个，一九七四到七五年，研讨班二十二期。实在界（the Real）——语言够不着、撞上去才知道的硬核——开始用新工具展开：博罗米结，法语 nœud borroméen。三只环，相互独立又互锁：任何一只断了，另外两只也散开。想象、象征、实在三界，就画成这样三只环。[/S2]

[S2] 第三个，一九七五到七六年，研讨班二十三期，加第四只环：sinthome，中文叫「圣状」，症状的变体。结不再自持，要靠这第四环维系。[/S2]

[S1] 所以文献的说法是：欲望图所属的「图式阶段」，连同莫比乌斯带、环面，被后期教学逐步取代，最终走到博罗米结。——阿哲最关心的问题来了：图作废了吗？白学了吗？[/S1]

[S2] 没作废。——但要把两句话分开：「取代为理论重心」是一句，「宣布失效」是另一句。前者是真的，后者没有。准确的画面是换重心，不是换地基。就好比盖楼：图是早年浇好的承重结构，后期教学换的是顶层设计，不是拆楼。[/S2]

[S3] 你这比方我得验一下。凭什么说没拆楼？——也许只是拉康自己不好意思承认。[/S3]

[S2] 证据在别人身上。一九八九年，齐泽克还站在这张图上做意识形态批判——图要是作废了，他站哪儿？更根本的判据：图和结回答不同层的问题。图问：意义和欲望怎么在能指链上缝合、定位。结问：三界和享乐怎么在实在中纽结、维系。——问题不同层，新工具不废旧工具。[/S2]

[S3] 我复述确认一下：图问「意义怎么缝合」，结问「三界怎么互扣」——问题不在同一层，所以新的不废旧的。[/S3]

[S1] 我来总结：图没过时，是理论兴趣搬了家——从「意义怎么缝合」搬到「三界怎么互扣」。——好，上主菜。这张图挨过的最重一炮，来自图外：德勒兹和瓜塔里一九七二年的《反俄狄浦斯》，法语原名 L'Anti-Œdipe。[/S1]

[S2] 先看清它打在哪个部位。这张图里，欲望的底座是匮乏——法语 manque，缺、少、欠着。主体因语言被划一杠，欲望因缺失而起，规则因禁令而立。德勒兹（Gilles Deleuze）和瓜塔里（Félix Guattari）拒绝的正是这个底座：欲望不是匮乏，是生产。[/S2]

[S2] 他们的说法是：欲望是机器——法语叫 machine désirante，一台接一台、不断组装新组合的机器{{voice:voice-003}}。原话大意：欲望的秩序，即生产的秩序。瓜塔里还给拉康的能指起了外号：专制能指——原文 despotic signifier，给一切定序、自己不被定序的词。[/S2]

[S3] 能不能展开说说——「欲望是生产」，生产什么？[/S3]

[S2] 生产「想要」本身。书里最出名的一段，是对禁令的拆解。原话大意是——「律法说：你将不娶你母亲、不杀你父亲。我们这些顺从的主体心想：原来这就是我想要的！」{{voice:voice-003}}——听出来了吗：不是欲望先存在、律法来镇压；是律法划出禁区的那一刻，「想要」才诞生。[/S2]

[S3] 我拿日常版验一下。——就好比家长宣布「这部动画绝对不许看」，孩子从那天起，才真正想追它？[/S3]

[S2] 对。——禁令不是欲望的狱卒，是欲望的助燃剂。[/S2]

[S1] 停一下，这里我得替拉康说句话。这条逻辑，《论主体的倾覆……》里明明也有——图的顶端就是被禁的享乐，第七期讲过。德勒兹这不是拿拉康自己的东西，打拉康吗？[/S1]

[S2] 问到点子上了。德勒兹不否认图里有这条逻辑，他反过来质问：既然禁令生产欲望，为什么还把欲望画成匮乏？画成匮乏，就是把欲望钉死在律法的影子里。这个底座在图上有三个落点：划杠主体的杠、欲望的「差一点」、大他者缺的那个词 S(Ⱥ)。他要拆的，正是这套「缺」的语法。[/S2]

[S3] 等一下——划杠的杠、欲望的差一点、大他者缺的词，三个都是「缺」。记下了：他要拆的是这套「缺」的语法。[/S3]

[S3] 那这场架的火力，到底落到图上没有？[/S3]

[S2] 没有直接落。——这是关键。《反俄狄浦斯》没有针对图形细节逐条开火，它批的是拉康的欲望概念整体：匮乏、能指、大他者{{voice:voice-003}}。攻击在概念层，图只是被殃及的装置。所以定性是：他不是批图画得不对，是批它把欲望画成了匮乏。[/S2]

[S1] 这两位后来还有互评。据说拉康夸过德勒兹：「我所需要的正是像你这样的人」；对方在访谈里回敬：「我们正是以精神分裂的方式帮助他」。——都是二手转述，听个意思。[/S1]

[S2] 还有更热闹的。中文网上流传：拉康读后极为震怒，还阻挠相关人士任教。故事传得绘声绘色，但学术来源交叉验证不了——拉康私下到底什么反应，这个我们也没搞清楚。评论区有懂的朋友，说说。[/S2]

[S1] 好，争议钉一下：批的是匮乏这个底座，不是图的零件；图还在原地工作。——而「还在工作」最好的证据，是下一组对照：同一张图，两个人用成了两样东西。[/S1]

[S2] 布鲁斯·芬克（Bruce Fink），拉康主要英译者，也是精神分析师。读法：临床、忠实文本、译者式。他最出名的一件事，是直说《论主体的倾覆……》这篇「不可读」{{voice:voice-005}}——评述文献转引。连主要英译者都嫌它难：这是真话，也是台阶。[/S2]

[S3] 不可读？那他还翻它？[/S3]

[S2] 正因为难，才要翻得忠实。他的战场在分析室：拿图读病人的话。另一边的齐泽克（Žižek）走完全不同的路：用黑格尔加马克思的框架，把图扛去做文化批判。书评人的说法是——读他的导论，「得到的黑格尔和马克思比预想的多」{{voice:voice-005}}。[/S2]

[S2] 齐泽克最著名的一次挪用在一九八九年，《意识形态的崇高客体》。他把缝合点——原词 point de capiton，第三期那个把意义钉住的点——读成了意识形态缝合{{voice:voice-006}}：主人能指（master signifier）——一串漂浮能指里的特权词——回头把其他词的意义钉死。[/S2]

[S2] 举个例子。自由、国家、正义、民主——四个词单独出现，都是漂的，各说各话。放进一句口号里：「共产主义」。四个词突然有了确定的方向和次序，还让人以为「意义本来就在那里」{{voice:voice-006}}——钉子按下去，漂浮结束，思路就是这样。[/S2]

[S3] 等等——钉子是「共产主义」，那钉子自己的意义，谁定？[/S3]

[S2] 没人定。——而且它拒绝被追问。这正是第七期 S(Ⱥ) 的逻辑：没有大他者的大他者，没有词给最后的词定意义，系统靠一个说不清的词维持。钉子抹掉自己痕迹那一下，又是第四期幻象的拿手戏：遮住不一致，让剧本看起来像自然。[/S2]

[S3] 我能不能这么理解：芬克拿图读病人，齐泽克拿图读口号——同一张图，一个在分析室，一个在讲座上？[/S3]

[S2] 对。两条路线学界真逐条对过账：女性享乐能不能言说、实在界怎么定义，答案都不一样。最细的一笔——齐泽克把驱力公式 $◇D 直接读成 sinthome；学者索科洛夫斯基（Sokolofsky）写了篇《拆解缝合点》逐点纠他：细读研讨班二十三期，$◇D 应是象征与实在交叉处的菲勒斯享乐，不是 sinthome{{voice:voice-004}}。连齐泽克阵营内部，都有人改他作业。[/S2]

[S1] 那咱们该选哪边？芬克，还是齐泽克？[/S1]

[S2] 我建议不选。值得记住的是另一件事：同一张图，能被两种用法同时用坏、用活。这说明它承载的不是答案，是一套传动。——答案会被新证据推翻，传动不会：谁都能把自己的料放进去跑。[/S2]

[S1] 好，三场争论走完，系列也该收官了。阿哲，爬完整座楼，你现在站在哪？[/S1]

[S3] 我用开场那句话答：图没白学。我现在说得出这张图回答的是什么——它不回答「你想要什么」，它回答「你为什么会要」。欲望不被回答，只被定位：在能指链上被构成、被缝合、被堵死、被遮住。[/S3]

[S2] 这段可以当结业证。再给你三件带得走的工具。读任何意义系统——一段话、一部剧、一个热搜——问三件事：它的缝合点在哪？什么词或时刻，让意义突然落定？它缺哪个词？说不出、绕开的那个缺位，S(Ⱥ) 的位置。它遮住了什么？什么幻象在盖住不一致。[/S2]

[S2] 这三问是「穿越幻象」的第一步——法语 traversée du fantasme，分析的终点不是实现欲望，是看清剧本，然后放得下。想继续走，有三条路：穿越幻象、意识形态批判、博罗米结。[/S2]

[S1] 后两条路，已经有人走出样子。意识形态批判那条，齐泽克一九八九年趟出来了；中文学界也有人往政治哲学上接——《世界哲学》二〇一九年有专文，从马克思主义方向用它{{voice:voice-010}}。入门这条也在长新路：网上已有成系列的拉康临床导论视频，读书社区的说法是——读拉康要「忘掉招式，找到你自己的风格」{{voice:voice-012}}。[/S1]

[S1] 最后一句话，还给第一期。这个系列是从一个梦开始的：梦不是秘密，也不是乱码，它是句子。八期之后再看这句话——梦是句子，句子会滑，滑到缝合点被钉住；钉子背后缺着一个词，缺的地方用幻象遮住。现在再走这张图，它不再绕行。[/S1]

[S2] 图讲完了，争论留着。——这本来就是它的命运：不是答案，是争论的起点。[/S2]

[S1] 系列到此收官。评论区见。[/S1]
