# 完整图合读：五条路径同时运转

上一篇爬完了最顶层——五条路至此全部见过面：传送带、马蹄、圆圈、镜子、顶层的链。但分开认识不算会读图：真正的图，是五条路同时运转的。本篇把完整图摆上桌，做三件事：先数清图上有几条路，再沿图走三遍，最后用一个完整例子，看一次深夜发朋友圈如何同时跑完全部五条路。

## 完整图：先数清楚，图上有几条路

先把篇 3 到篇 7 的局部拼回整张图（示意图，不是临摹——但该在的位置都在：$◇D 在最上层，缝合点在链尾，镜像层在右侧）：

```
        △ 纯粹需要的主体（进链之前）
         \
          \           [上层链] 无意识 · 陈述活动层
           \          双重铭刻：下层的无意识回响
            ×──── 享乐（S(Ⱥ) 缺位之词所在）──▶ 阉割
           /  \                                    │
          /    \                          $◇D（驱力，写在代码位置）
         /      \                                   │
        /        \                                  │
       /          d（欲望）── $◇a（幻象）───◇─────┘
      /
      │            [下层链] 意识 · 陈述层
      ×──── 能指 S ──▶ s(A)（缝合点）──────▶ 语音
      │                                         │
      │                                 I(A) m i(a)
      │                                         │
      ▼                                         ▼
   $（划杠主体）                          A（大他者）
```

两条横线是两条平行叠置的链：下层「能指→语音」是陈述层（statement / énoncé——说出来的话本身），上层「享乐→阉割」是陈述活动层（enunciation / énonciation——「正在说这句话」这件事，无意识那一层）。一条马蹄形的矢线从 △ 垂到 $，再折向右上。记得篇 1 的约定：图上没有一条线是欲望本身，每条线都是结构。

这张图不是一次画成的：Graphe 1（法文版《Écrits》p.805，基本单元）→ Graphe 2（pp.808-809，镜像层）→ Graphe 3（p.815，「被叠加的那一层」——Che vuoi? 与上层链）→ Graphe complet（pp.816-820，完整图；「Graphe 4」只是评述界的顺推叫法）。

但拉康在研讨班第六期首讲（1958 年 11 月 12 日）交代过：别把四步当「阶段」——是生成，更准确地说，是「每个图式相对于后一个图式的逻辑在先性」。四图是教学装置，不是时间演化；图始终作为整体存在。

现在数路。拉康的原话（《论主体的倾覆…》Graphe 1 评注段，褚译）：「意义连环是被看作由向量 S·S' 所承载……在这个逆向上产生了与向量 ΔS 的双重交叉。只有在这后一个向量上我们看到了逮住的鱼儿。」图上有五条路：

**路一：能指链 S→S′（下层横线）。** 陈述层——你说出口的那句话本身。它是被穿过的路，自己不主动走；方向从左到右，意义事后（après-coup，篇 3 的「倒着长」）才落定。S′ 读作表意（signification）——意义产生的过程本身，不是成品。

**路二：主体矢线（向量 ΔS，马蹄形）。** 从 △/$ 出发，向右下穿过能指链（第一处交叉，代码点），折上大他者 A，再从 A 落回链尾（第二处交叉，s(A) 讯息点）——这就是「双重交叉」。「只有在这后一个向量上我们看到了逮住的鱼儿」：欲望不活在链上，活在这条矢线上。

**路三：屈从圆圈 s(A)→A→s(A)。** 路二的后半截单独收成环。褚译原句：「主体对能指的屈从产生在从 s(A) 到 A 随后又从 A 回到 s(A) 的路程中的。这个屈从是一个圆圈。」——篇 5 的「需求的环形地狱」就是它：

```
   s(A)（缝合点·讯息）──▶ A（大他者）
     ▲                      │
     └── 回来，还是差一点 ────┘
```

**路四：镜像路 i(a)→m（头顶压着 I(A)）。** 图式 2 加的想象层矢量：从镜中形象（i(a)，他者的形象）到自我（m），再被自我理想（I(A)，大他者的理想）锚定——篇 6 那张「盖缝的画面」，叠在图的右侧。

**路五：上层链 享乐→阉割。** 完整图的上层矢量链（Jouissance → S(Ⱥ) → $◇D → Castration，法文版 pp.816-817），图式 3 叠加的那一层，与下层结构完全相同——双重复制（duplication）。上层享乐区住着两个符号：缺位的词 S(Ⱥ)（「没有大他者的大他者」；父之名与亡父神话在此安置）和不可企及的大他者的享乐（J(A)）。

驱力 $◇D 不另算一条路——它是路五上的绕圈点，写在代码的位置（Seminar VI 首讲那个「能指的电池」）。驱力（pulsion / drive）的定义原文是：「要求中主体消隐后剩下的东西」（法文版《Écrits》p.817）——注意，不是「需要变成了驱力」。

五条路的传动一句话：路一、路五上下对称，路二穿过它们，路三圈住主体，路四贴着镜像层。任何一条动，其他四条都在场；篇 1 的两句公式也各就各位——欲望是换喻，症状是隐喻。

## 三遍走法：同一张图，三种读法

**第一遍，自下而上——拉康搭楼的方式。** 阶段一，基本单元：能指链 S→S′ 与矢线相交于 s(A)，意义被大他者「事后」钉住（篇 3 那个句号）；阶段二，镜像层：自我 m、形象 i(a)、自我理想 I(A)。

阶段三，「Che vuoi?」与幻象：大他者把问题抛回给你，欲望 d 经幻象 $◇a 回应；阶段四，驱力、阉割、享乐与 S(Ⱥ)：$◇D 写在代码位置，顶端是缺位的词与被禁的享乐。注意拉康的告诫：四阶段是逻辑在先性，不是时间演化。

**第二遍，自上而下——上层是下层的无意识回响。** 这是双重铭刻（double inscription）的几何化，也是篇 1「无意识像语言」的落点：同一句话同时载两层意义——下层说「我能行」，上层在说「我要你看见我」；嘴上说「够了」，驱力还在绕。上层「享乐→阉割」正是下层「能指→语音」的回声：每个句子同时是「一句话」，和「一个欲望在陈述活动层发生的事」。

**第三遍，从左往右——主体的生成。** △（进链前的纯粹需要）穿过「能指的隘口」被划杠成 $；$ 开口要，需要变成要求（demande，对爱的无条件要求）；要求与需要之间的缝隙里，欲望 d 涌现；d 经幻象 $◇a 得到一个位置；最后 $◇D 在最上层把一切拖进绕圈的回路。从左往右，就是从「还没进入语言的存在」，读到「被语言组织完毕、还在绕圈的存在」。

三遍走完，拉康自己的一句话可以落地。图用来「标明相对由能指在其陈述中规定的主体而言，欲望的位置在哪里」（褚译）；同时区分三样常被混为一谈的东西：被压抑者（le refoulé）、欲望（le désir）与无意识（l'inconscient）——三者不是一回事。整图的叙事：欲望没有被回答，它被定位了。

## 一个完整例子走全程：深夜的朋友圈

场景：深夜十一点，你加班回家，编辑了一条朋友圈：一张办公桌照片，文案「又是充实的一天」。按下发表。接下来几小时，五条路同时运转。

**发出之前——路二已经在跑。** 按下发表的那个动作里，「想要什么」？疲惫需要被看见——需要（besoin）是沉默的；开口要的是被回应——要求（demande）把一切满足转译成爱的证明；而两者之间那道缝里，欲望 d 冒出来：点赞落下来也填不满的东西。它不在文案的任何词里——「表达自我」的结果，是语言表达它自己。欲望是换喻：追一个又一个目标，点赞、加精、被转发，没有一个停得住（篇 4 的鞋、机器、票）。

**发出之后——路一滑动。** 那一串能指上了传送带。「充实的一天」是什么意思？还不知道。它会被当作自嘲、求助还是炫耀，取决于之后被怎么标点——滑动是常态，不是故障。

**点赞落下——缝合点 s(A) 钉住。** 第一条点赞落下（或迟迟不落），意义开始落定。篇 3 说句号不是说话的人打的；这次换成：句号是听者那一侧打进来的。点赞是句号；句号未落，文案悬空。

**然后你开始等——路三转圈。** 你反复点开手机。等谁？不是等某个具体朋友，是等大他者——能指的宝库、语言本身的总仓库。每刷一次，屈从圆圈就转一圈：s(A)→A→s(A)。大他者不回答，只反抛「Che vuoi?——你想要什么？」；越等越虚，每一圈都差一点——篇 5 讨好型人格的环形地狱，朋友圈版。

**你选照片时——路四早就在场。** 为什么是这张照片而不是那张？因为你在维护一张人设：编辑过的自画像（i(a)→m），而「被看见时应当成为的样子」由自我理想 I(A) 锚定。点赞是评分，评分回馈镜像，镜像加固人设——篇 6 里母亲的表情，早已换成朋友圈的期望画像。

**凌晨一点——路五顶层。** 你放下手机：「够了，不刷了」。但手指还在刷。嘴上说「够了」在陈述层；陈述活动层里，驱力还在绕。「再多一点，哪怕过头」——这是享乐（jouissance，吴琼译「原乐」），不是快乐：快乐是刚刚好，享乐是「够了」之后还不停。

**停不下来——$◇D，驱力。** 最后这层最像你本人：这不是「想要更多点赞」的欲望——欲望还知道自己在要什么方向的东西；驱力不问「想要什么」，只绕圈、重复。$◇D 写在代码的位置：你用的每个词都来自那个词库，连「停不下来」也是从那里借来的。

深夜刷手机等的其实是那一声提示音——语音召唤（pulsion invocante，被喊到名字；篇 7 讲过它最接近无意识的经验）的日常形态：在成为「喊别人的人」之前，你先是被召唤的那一个。

一条朋友圈，五条路全部在场。删掉这个例子，逻辑依然成立：任何一句话、任何一个「想要」，都是同样的五路传动——这就是「图始终作为整体存在」的意思。

## 三问自检清单：全系列的落点

图读完了，留三件工具。以后读任何意义系统——一段话、一部剧、一个热搜——问三件事：

**一，缝合点在哪？** 什么词、什么时刻让意义突然落定？找到它，就读出了意义的生产线——那是 s(A)（缝合点 point de capiton）的位置。

**二，缺哪个词？** 那个说不出、绕开的缺位——S(Ⱥ)，大他者缺一个词，「没有大他者的大他者」。制度的「最终解释权」一路问上去，最后落在一个说不上来的词上；缺位的词在哪，系统的裂缝就在哪。

**三，遮住了什么？** 什么幻象在盖住不一致？幻象公式 $◇a 里的 a 是客体小 a（objet petit a，欲望的成因，不是欲望的对象——主流五数：乳房、粪便、目光、嗓音、菲勒斯；另有一说补「空无」）。篇 4 的填空练习「如果我____，我就踏实了」——填出来的就是剧本；问出这一句，剧本就露了底。

这三问就是「穿越幻象」（traversée du fantasme——不是实现欲望，而是看清剧本）的第一步。正如全系列反复说的：这张图不回答「你想要什么」，它回答「你为什么会要」。

## 小结

五条路径怎么互锁：路一、路五上下同构，路二穿过它们，路三圈住主体，路四贴着镜像层——一条朋友圈、一句话，五路同转。图的叙事始终是：欲望不被回答，只被定位。自检三问（缝合点、缺位、遮蔽）就是全系列的落点。

但图不是悬在真空里的。它被人读过、批过、挪用过：中文世界的翻译之争，德勒兹「欲望是生产不是匮乏」的进攻，Fink 与 Žižek 对同一张图的两种用法。「别人怎么说」也是图的一部分——下一站，走出图，看它怎么被争论。
