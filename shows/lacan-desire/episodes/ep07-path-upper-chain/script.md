# 路径五：上层链（享乐→阉割）

上一站，镜像路走完了：图右侧那张「完整的脸」只管「我看起来像什么」。但图最顶上还压着一条路——它不管像不像，管「够了还想再要」。这期爬最顶层。顶上没有奖杯：那里住着被禁的享乐、一个缺位的词，和一个停不下来的绕圈。

## 上层链与双重复制：两条一模一样的链

完整图（Graphe complet，法文版《Écrits》pp.816-820）里有两条横链。底部那条我们早就认识了：从能指（S）到语音——那是你说出口的话，叫陈述层（énoncé，法语「所述内容」）。顶部还有第二条：从享乐到阉割——话里没说的那一半，叫陈述活动层（énonciation，法语「言说这个动作本身」）。这条顶层横链就是上层链：图最顶上那条路，整张图的无意识层。

关键在结构：拉康把两条链画得完全相同——这叫双重复制（duplication）。下层链是从能指射向语音的箭头，上层链是从享乐射向阉割的箭头，节点、方向一一对应。这不是排版巧合。篇 1 说过无意识像语言：同一句话同时载着两层意义，一层在陈述层，一层在陈述活动层。拉康在 Seminar VI 次讲（1958 年 11 月 19 日）里特意强调：这两层绝不对应于通常的上下功能建筑——在最小的言语行为里，两层同时运作。

承重例子：嘴上说「够了」，手指还在刷。「够了」是陈述层的内容；手指不停，是陈述活动层在绕圈——一句话，两层意思，同时运转。删掉例子逻辑照旧：任何说出口的话都同时挂在两条结构相同的链上，一条管「说了什么」，一条管「说本身在干什么」。

上层链在第三张图（Graphe 3，法文版 p.815）就以「被叠加的那一层」的形式出现，完整图里收齐。它的完整走法是：享乐的位置 → S(Ⱥ) → $◇D → 阉割（法文版 pp.816-817）：

```
   陈述活动层 / 无意识层（话里没说的那一半）
   --------------------------------------------------
        S(Ⱥ) ---------> $◇D ---------> 阉割
    （享乐的位置：    （驱力：写在     （castration：
     「这地方叫享乐」） 代码的位置）      离开圆满的代价）
   --------------------------------------------------
   陈述层 / 意识层（你说出口的话）
        S（能指） ----------------------> 语音
```

先认链的终点：阉割（castration，去势）。它不是一场惩罚，没有刽子手——它是给「离开圆满」起的名字：婴儿曾经和母亲的身体贴在一起，那个状态是「全要」的；进入语言，等于离开这个圆满，代价是永远差一块。你为「不能全要」付的代价，就是阉割留下的痕迹。现在往回走，看链的第一站：享乐。

## 享乐与快乐：刚刚好，再多一点

先纠正一个翻译事故。享乐（jouissance——法语里的日常词「享受、快感」，所以早年被译成「快感」）说的根本不是快乐。弗洛伊德的快感原则（pleasure principle）是趋乐避苦、把张力压到最低——快乐是「刚刚好」。享乐恰恰相反：再多一点，哪怕过头。它不保存你，它消耗你，所以常常和痛苦搅在一起。吴琼特意译「原乐」，说它是对快感原则的超越、对法的僭越——法是什么，下一节揭晓。

一块蛋糕：第一口是快乐——甜、满足、刚刚好。第三口、第四口，舌头说够了，手还想再切一块。那股「够了还来」的劲儿就是享乐。复吸的那一口、凌晨两点「再刷五分钟就睡」的五分钟，都是同一个结构：不是追求最大快乐，是要多一点、再多一点，哪怕伤到自己。所以拉康说，人不是被快乐驱动的——那根不许顶破的管子顶破时喷出来的，才是享乐。

拉康给图的顶端一行留了句标注（法文版《Écrits》pp.819-820，Fink 英译本页边标注法文页码）：这地方，叫做享乐（This place is called jouissance）。紧接着（p.821）又补了一句更硬的：对说话者而言，享乐是被禁止的（la jouissance est interdite à qui parle comme tel）。为什么被禁？禁令是谁下的？下一节。

## S(Ⱥ)：大他者缺一个词

下禁令的位置，叫父之名（Nom-du-Père / Name-of-the-Father——给规则盖章的那个空位，一句人话：「不能全要」）。先纠误会：父之名不是某个具体的爸爸，也不是「父权」。它是象征功能——语言里那个「说不出口但人人都默认」的禁令位置；想象里的父亲（爸爸这个人）只是这个空位的化身。爸爸可以软弱、缺席、破产，规则照样生效——生效的不是这个人，是「父亲」这个位置。

但拉康把问题再推了一步：规则的颁布者之上，还有颁布者吗？1960 年的《论主体的倾覆和在弗洛伊德无意识中的欲望的辩证法》（《Écrits》）里有那句著名断语（法文版 pp.818-819 交界，逐字）：这里所说的匮乏，正是我们已经表述过的东西——没有大他者的大他者（qu'il n'y ait pas d'Autre de l'Autre）。

大他者（A，能指的宝库）自己缺一个词。拉康把这个缺位记作 S(Ⱥ)（signifiant du manque dans l'Autre，大他者的能指匮乏——大他者中缺掉的那个能指）。

承重例子：翻开任何一份规章制度，最后一行通常是「本规定的最终解释权归某某」——可那个「某某」的解释权，又由谁来解释？一路问上去，最终落在一个词上：那个词自己不解释自己，也没有别的东西替它解释。这个说不上来的词，就是 S(Ⱥ)：整个意义系统里注定缺位的一颗钉子。删掉例子逻辑照旧：象征秩序没有终极担保人，能指系统本身不完整，没有元语言。

拉康在这里安置的不是活着的父亲，而是弗洛伊德神话里的亡父——《图腾与禁忌》里被儿子们联合杀死的原始部落之父。为什么必须是亡父？因为死人是最可靠的立法者：不会改口、不会收回成命、不会被推翻。活着的父亲可以被挑战；一个死去的名字不行——它什么都不做，只留下一个空位，规矩从这个空位里说话。

S(Ⱥ) 不是「大他者藏起来的答案」——是结构性的缺失。评注者 Soler 给它一个集合论的出身：一个集合不能既一致又完备，「所有能指的集合」要自证完整，必须有一个在集合之外的元素来点数。数指头：数完十个，发现「少了一根」——能数的那根手指，不在被数的指头里。同住顶层享乐区的还有大他者的享乐 J(A)——它不是「大他者拥有的某种爽」，而是「爽」这个字在象征秩序里的缺席本身。

## 驱力 $◇D：写在代码位置的绕圈

现在回到那条禁令。享乐被禁了，人绕开走就是了——可你绕的恰恰是它。被禁的享乐，为什么反而把人吸在原地？因为绕圈的不是欲望，是驱力。

驱力（pulsion / drive——弗洛伊德的老词 Trieb，中文旧译「冲动」）。它和欲望差在哪？欲望（désir）有方向，指着永远差一点的目标（篇 4：欲望是换喻）；驱力不问「想要什么」，它没有目标点，只有回路。图上的写法是 $◇D：划杠主体 $ 与要求 D 用那个「包含与不可能」的符号（◇）扣在一起——和幻象公式 $◇a 同一个 ◇。拉康给驱力的定义一句话说死（《论主体的倾覆…》法文版 p.817，逐字）：驱力是「要求中主体消隐后剩下的东西」（ce qui advient de la demande quand le sujet s'y évanouit）。注意措辞：不是「需要变成驱力」——是主体在要求上走到消隐，剩下的那个绕圈的东西。

位置是关键：$◇D 写在代码的位置。代码（code）不是密码本——它是词库＋规则，约等于语言本身：你开口用的全部能指。为什么驱力贴在这里？因为主体正是在代码处被构成的。拉康的原话（出自《Écrits》Graphe 1 的评注段，法文版 pp.806-807——注意出处是《Écrits》，不是研讨班讲稿）：

> 主体由代码构成，这意味着，连他自己发出的讯息，也是从大他者那里接收的。

同段还说明：大他者 A 是能指宝库的位置，「并不是说就是代码」——宝库是地点，代码是构成层。而 Seminar VI 首讲（1958 年 11 月 12 日）里，拉康把代码处形容为「能指的电池」：他问，最小电池能不能构成一种语言？「四个的电池」（une batterie de 4），并非不可设想。虚线与能指链相交的两点里，第一处就是代码点，第二处才是讯息点：

```
    （虚线=要求/矢线，切过能指链两次）
         \                \
          \                \
   S ──────×────────────────×────────► 语音
           ①                ②
       code（代码）     message（讯息）
    $◇D 就写在①「代码的位置」
```

还有一处查证结论要钉牢：$◇D 属于最上层（阶段 4，与享乐、阉割同层），不在第二层——No Subject、Wikipedia、Soler、Eidelsztein 的讲法一致。为什么位置这么要紧？因为绕圈这件事不在图的基层，而在离享乐最近的地方：满足的终点被禁掉了，剩下的就是一个没有终点的回路。

承重例子：深夜刷手机。你已经「不想看了」，手指还在上滑——嘴上说「够了」，手不听，因为有个声音在喊「还不够」（篇 5 的超我）。那个声音没有面孔，就在你耳朵里。删掉例子逻辑照旧：驱力是主体在要求上消隐后剩下的回路，它贴在构成主体的代码位置上。

## 语音召唤：被喊到名字之前

驱力绕的那个圈，绕的是什么对象？——语音。语音召唤（pulsion invocante / invocatory drive——以语音为对象的驱力）是拉康在 1964 年 3 月的 Seminar XI《精神分析的四个基本概念》驱力诸讲里正式命名的。原句（法文版《四概念》p.96，回应萨福安提问时说的，逐字）：在观看层面，我们已经不在要求的层面，而在欲望、在大他者的欲望的层面；召唤性驱力亦然，它最接近无意识的经验。

这个概念有一条长长的前史，拉康把三个画面排在一起。第一个：fort-da——弗洛伊德的孙子把线轴抛出去又拉回来，「fort！（没了）」「da！（回来了）」。拉康注意到这游戏的咒歌式特征：孩子口中那些「会唱歌的音素词」先于任何意义，已经是一个绕声音的回路。第二个：shofar（公羊角号）——Seminar X《L'Angoisse》1963 年 5 月 22 日那一讲，拉康引雷克（Theodor Reik）的话：shofar 说到底不是别的，是上帝的声音、雅赫维的声音；又点破它的位置：弑父及它所统摄的一切，在号声里回响（STA-F 讲稿逐字）。一个字都没有，但整个共同体站住了——语音召唤不必是言语。

第三个：蒙克《呐喊》——画中人捂着耳朵、张着嘴，被声音淹没却喊不出声：被召唤、却还不会召唤的姿势。

（一句诚实交代：「象征界的来临」是评述者的转述，不是拉康原话，这里不引。）

图上的落点也有讲究。下层链的终点不是「意思」，是语音；上层链的终点是阉割——拉康把语音与阉割放在图的同一侧（法文版《Écrits》pp.816-818）：

```
   [上层]  S(Ⱥ) -------> $◇D -------> 阉割
                                        │
                                        v ← 同一侧
   [下层]  S（能指） ----------------> 语音
```

绕圈绕到最后剩下的那个东西——声音——正守在享乐被禁的切口旁边。查证边界也交代一句：「invocation」并没有作为独立节点被直接标注在图上；本系列按有据的链条写作：语音＝下层链终点＋召唤性驱力的对象＋与阉割同侧。

承重例子：点名。老师喊「张三」，你应声——那个「是」不是你想好了才说的。在你来得及想「我是谁」之前，一个声音已经占住了一个位置，你应了。你以为你是说话的人，可在这之前，你早就是「被喊的那个人」：主体最先的形态不是说话者，是被召唤者；能喊别人名字（成为召唤者），是后来的事。删掉例子逻辑照旧：声音先于意义，召唤先于说话。

## 小结：顶层是缺与禁

至此五条路全部走完。顶层链三件事：一，上层链与下层链结构完全相同（双重复制）——一条管「说了什么」，一条管「说本身在干什么」，最小的一句话里两层同时运作；二，享乐是「再多一点，哪怕过头」，被父之名的禁令钉死；S(Ⱥ) 就是大他者缺掉的那个词——没有大他者的大他者，缺失的钉子，安置着亡父；三，$◇D（驱力）写在代码的位置——驱力是「要求中主体消隐后剩下的东西」，只绕圈，不追目标；它绕的那个圈对着语音召唤：你是先被喊的，然后才学会喊人。

顶层没有奖杯：一个缺位的词，一道禁令，一个回路。图的顶端是结构性的失败——能指在享乐的位置缺席，享乐被禁。但别忘了，五条路是同时运转的：能指链滑动、缝合点钉住、矢线追目标、圆圈转不停、镜像盖缝、驱力绕圈——没有先后，只有同时。这就是为什么嘴上说「够了」，手指还在刷：你整个人就是这张图。

五条路都走完了。现在该把图完整摆上桌，看这些零件怎么同时传动。
