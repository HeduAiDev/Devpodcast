# 概念准备（下）：谁在说话

上篇结尾，我们把「意义到底在哪停下」挂在了链尾——要回答它，得先认识链上的两个「人」。说话的那个「我」先来：开口之前，他真的存在吗？

## 划杠主体 $：语言的产品，不是语言的主人

笛卡尔说「我思故我在」：思考的那个我，就是存在着的那个我。拉康把这句话整个拧了过来。他在 1957 年的《无意识中字母的动因》（《Instance of the Letter》）结尾写下：「我在我不在之处思，故我在我不思之处在」（英译本《Écrits》p.166）。

拆开读：思想发生的地方（能指链上），与「我存在」的地方（语言够不到的地方），不是同一个点。你以为自己是思想的起点；拉康说，你只是思想经过的一站。

精神分析的主体不从「我思」出发，而从「它思」出发——法语写作 ça pense：有什么在思，恰好经过我。「我」不是思的主人，是思的路过地。英语 subject 还藏着机关：它兼有「主体」与「臣服者」两义，拉康取的是后者——主体是符号秩序的效果，不是符号秩序的主人。「你说话」的真相，是「话说你」。

图上这笔账这么记。左上角有个三角号 △：还没开口的、沉默的主体——这是拉康事后倒推的「神话」起点，没有人真的在语言之前存在过。它要进入语言，得穿过一条窄巷：能指的隘口（defiles of the signifier，进语言必经的那道关）。穿过去之后，△ 变成了 $：划杠主体（sujet barré / barred subject），一个被杠穿过的 S。

杠从哪里来？一旦你用语言表达自己，表达出来的永远不是「你」，而是语言说得出的那个版本。试试就懂：你永远说不出「完整的我」。自我介绍、写简历、跟朋友解释「我其实是个怎样的人」——每一次开口，都是在给语言递一张照片；照片再像，也只是语言能说出的那个版本。越解释越明白照片不是自己，那道杠就越深。删掉这个例子，逻辑照样在：$ 不是残缺的个人，而是结构位置——语言对任何说话者的构成本身就制造缺口。

## 大他者 A：你在跟「语言本身的总仓库」说话

那听你说话的那一头是谁？图右上角站着 A：大他者（Autre / the Other），能指的宝库（trésor du signifiant / treasure of the signifier）——一种语言里全部能指的集合，整个象征秩序。褚孝泉译作「能指富藏的地方」。先排除最常见的误会：它不是爸妈、不是老板、不是社会排行榜——那些是具体的人或机构；A 是一个结构性位置。

想想你发朋友圈的经历。精心措辞：配哪张图、用哪种语气、加不加标点——你到底在跟谁说话？任何一个具体读者都撑不起这个排场：点赞的亲戚不是靶子，潜水的前同事也不是。真正在听的是「语言本身的总仓库」：这句话被当成幽默还是冒犯、值不值得点赞，判定权在那套语言规则手里，不在任何一个人手里。

删掉这个例子，逻辑还在：讯息的意义由接收方回溯决定（上篇结尾那个『意思要到哪个瞬间才算落定』的问题），而接收方的位置就是 A——你发出的每一句话，都先在大他者的仓库里登记过，才轮得到你「发出」。

拉康在正式论文里把这句话说绝了。1960 年 Royaumont 会议报告《论主体的倾覆和在弗洛伊德无意识中的欲望的辩证法》（1966 年收入《Écrits》，法文版 pp.806-807）：「主体由代码构成——因此，连他自己发出的讯息，也是从大他者那里接收的。」

你以为自己在发出讯息；准确说，是你先从大他者那里收到它。（这里的「代码」先别跟大他者划等号——拉康在同一段特意做了区分，第七篇讲上层链时再拆。）再补一个日常时刻：点名。老师念你的名字，你应一声「到」——「你」的位子，就这么被名单上那个词确认了。名字住在哪里？户口本、花名册、考勤表——都在语言的总仓库里。大他者用名字召唤你，你才「在册」；这一声「到」，是主体被语言登记的时刻。

```
        △                          A（大他者）
        |                          |   能指的宝库
        |    马蹄形矢线：         |   语言的总仓库
        |    △ 出发 → 下行 →      |
        |    沿链 → 上行 → 讯息  |
        |                          |
   S ----+-----------------------+-------> S′
        |                         ^
        $                        s(A)
   （划杠主体）          （讯息点：句号由大他者打）
```

示意图，只标位置，不是临摹：横线是能指链 S→S′，说话的人 $ 被压在链底下，听话的位置 A 守在链上头。马蹄形矢线是欲望的路线——先认位置，第四篇细走。一眼就能记住：A 和 $ 不是同类，一个是被语言划伤的，一个是语言本身的位置。

## 自我 m vs 主体 $：画面用来盖缝

但你平时挂在嘴边的「我」——照镜子那张脸、朋友眼里的那个人——不是 $ 吗？拉康说：那是另一回事，别混。那个「我」叫自我（moi / ego），来自镜像阶段（stade du miroir / mirror stage）：婴儿在镜子里认出「那个完整的身影是我」。

关键在下一步：镜中的形象是借来的——它是他者的形象（i(a)，image de l'autre：「像我的人」的形象，不是你本人）。自我 m 是建立在误认（méconnaissance，把不是自己的形象认成自己）之上的想象构成：把一个其实是分裂的东西（$），拼成一张连贯的自画像。它的功能只有一个：补偿。

```
      i(a) ---- m
   （他者的形象）（自我）
     想象层 · 面对面
```

图右侧这一小块是镜像层：自我 m 和他者的形象 i(a) 面对面站着。m 是一张画面，$ 是一道缝——画面用来盖缝，而它盖不住。头顶还压着一个符号 I(A)，讲镜像路（第六篇）时再拆。

照镜子，看见的那张脸不是「你」，是「看起来像你的形象」；自拍修图更是把这件事做到了明面上——磨皮、瘦脸、滤镜，修的是 i(a)，不是 $。$ 没法修：它不美不丑，它只是缺。删掉修图的例子，逻辑还在：自我是误认的想象构成，功能是补偿主体在语言中的分裂——自画像修得越完整，越说明底下那道缝修不上。

## 需要、要求、欲望三角：那道盖不住的缝

现在把镜头切到最早的说话现场：婴儿饿了，张嘴啼哭。这一声哭，要的真的是吃的吗？

拉康给这一层起的名字：需要（besoin / need）——纯粹的生物性不足：血糖低了、胃空了、身体报警。注意它有什么、没什么：它有「不足」，没有「意义」。哭声还不是语言，甚至还不是「我要」——「要」得先有个「我」的位子，而此刻还没有。

一开口就变味。婴儿迟早会对着妈妈咿咿呀呀——从那一刻起，对满足的需要就变成了要求（demande / demand）：用语言、对着大他者索要东西的那个动作。拉康的原话：需要被「转译成爱的证明」（transmutes them into proofs of love，《Écrits》）。

你哄过孩子就懂：奶瓶塞过去，孩子喝了，还是闹——他盯着你的脸。他要的不是奶，是奶被笑着递过来。任何具体的东西（奶、玩具、抱抱）只够当一次爱的证明；「证明」要多少才算够？永远不够。所以要求是无条件、绝对的——不是孩子贪心，是语言的结构：具体的东西一说出口就落进能指链，成了下一个能指的替身，而能指链永远指向下一环。

两个词之间，漏出第三样东西：

```
   △  需要（need）：沉默，没有意义
   |
   |  开口——进入语言
   v
   $  划杠主体：被语言切开
   |  ← 盖不住的那道缝
   |    d（欲望）就住在这道缝里：差一点，永远差一点
   v
   D  要求（demand）：对爱的无条件证明
```

这个竖列是三角的骨架：△ 是沉默的需要，开口穿过语言变成 $，开口这个举动本身是要求 D；D 与 △ 之间那道永远合不上的缝，就是欲望（désir / desire）——第一站预告过的那个「还差一点」的东西。吴琼在《雅克·拉康：阅读你的症状》里给过一个著名公式：欲望＝要求－需要。

要求是「对爱的无条件要求」，需要是「沉默的机体报警」，一减，剩下的那道缝就是欲望：被说出来、却永远超出要求的剩余——任何客体、任何爱的证明都填不满它，因为它的对象不是某个东西，而是「差一点」本身。

拉康的原句（《Écrits》法文版 p.814）：欲望在要求从需要撕裂开的边缘涌现（Le désir s'ébauche dans la marge où la demande se déchire du besoin）。注意「撕开」：要求像一层布盖在需要上，盖不严，边缘总露着缝——欲望就住在这道缝里。

顺带一个译名陷阱：中文一个「需求」常把「需要」「要求」糊成一样，三角坍成两角——本系列坚持分开写。两个台阶先记下：「欲望本身」要到俄狄浦斯之后才完整成形，今天先立三角；要求的「永远不够」在图上是绕回大他者的一个圈（s(A)→A→s(A)），形状先记住，第五篇专门走它。

## 小结：两个人，一张画面，一道缝

这一站的四块砖：$ 是穿过语言的划杠主体——语言的产品，不是主人；A 是大他者——能指的宝库，不是某个人；m 是照镜子拼出来的自我——形象是借来的（i(a)），画面用来盖缝；需要、要求、欲望——沉默、开口、差一点，三角立在语言边上。

现在链上的两个「人」认全了：说话的 $，和听话的 A；两条路也认了个形状：能指链，和要求的圈。下一站开始逐条走——先走最底下的那条路：能指链本身，看意义到底怎么动、句号到底由谁打。
