# 第 3 期：你省的不是 token，是物理块——一块显存的一生

> 淘汰了 90% 的不重要 token，重启服务，显存几乎没降——因为显存是按「块」还的，不是按 token 还的。

## 本期简介

一道面试题开场：你给 vLLM 加了 KV cache 压缩，淘汰了 90% 的不重要 token，重启后显存几乎没降，同样的长度照样爆显存。答案不在淘汰了多少 token，在淘汰的单位——KV cache 被切成 16 token 一块的物理块，只要一块里还剩一个 token，整块就释放不了。

本期顺着这块显存走完一生：从块池出发，经过 LRU 排队、前缀缓存共享、分配失败被抢占，住进跨拍存活的持久批次，最后被块表送进 GPU。机制讲完，围绕「16 这个块大小到底谁定的」打了一场社区争议。

## 本期要点

- **为什么切块**：KV cache 是活的，随对话长度只增不减，长上下文下是显存大头；按最长长度给每个请求预分配纯靠猜，浪费惊人还怕碎片——vLLM 从操作系统偷了虚拟内存的主意，切成 16 token 一块，散落的块由 PagedAttention 算子按块寻址
- **块池与空闲队列**：全局块管家管三样家当——块的名单、空闲块队列、前缀缓存查表；空闲块串成双向链表，队头最久没用先被赶，中间删除 O(1)；驱逐是惰性的，不够了才赶，被赶只是「可分配」不是销毁
- **前缀缓存**：满 16 颗 token 的块才算哈希当钥匙，查表找最长前缀命中；刻意不去重，保住块表只增不改；引用计数归零才真正还块——计数出了 bug 就是泄漏
- **三段式分配**：先释放窗口外旧块 → 挂前缀命中块（本地缓存和外部预填充一视同仁）→ 开新块 + lookahead 提前占位；失败是「这拍发不出来」的正常返回值，不是异常
- **抢占与双队列**：分配失败触发抢占循环——拽下 RUNNING 队尾、块归还、回队头插队补偿、本拍不再放新请求；token 预算不够的请求挪进独立侧道，不许堵队头，防队头阻塞
- **持久批次**：请求批不每拍重建——一行一请求的定长容器，每拍发「变更单」差量更新，worker 拿快照就地改；请求退房留洞、洞攒多了才压实；赌的是「大部分请求活着跨拍」
- **块表最后一公里**：CPU/GPU 双镜像、攒够了批量同步；Triton 内核把「逻辑块号 × 16 + 块内偏移」翻译成物理槽位，尾部占位符适配固定网格
- **争议判据**：块大小 16 不是圣旨——唯一 prompt 场景分页只有碎片、块越小越好；多租户 Agent 场景 80% 共享系统提示词，前缀缓存收益压倒一切碎片。选块大小，本质是判断你的负载属于哪种

## 引用的社区声音

- **腾讯云开发者社区（2026-06）**：KV cache 压缩淘汰 90% token 显存没降——答案在释放了多少个完整物理块，一块还剩一个 token 就释放不了
- **牛客面经 @DecIus（2026-03）**：前缀缓存哈希粒度是什么？不满一块的前缀能不能缓存？固定系统提示词、用户 query 不同时命中率怎么估——AI Infra 实习岗真问
- **CSDN 博主 z1ztai（2025-08）**：面试官让手写 PagedAttention 的实现逻辑，群里一位同学当场被问懵——「手写 PagedAttention」能进面试，说明切块是理解 vLLM 的入场券
- **牛客面经转述面试官递进追问（2026-06）**：块大小设为 1，碎片没了但块表暴涨；默认 16 一块只用 15 颗，剩下一个空位整块也释放不了——内部碎片
- **GitHub issue @wenqin（2025-03）**：分组查询注意力下旧内核 8 个线程块重复加载同一份 KV 头数据，L1/L2 之间流量跑了 800 多 MB、实际只有 64 MB，他给的新内核性能提升约三成
- **Mistral AI 生产环境（2026-06）**：UCX 钩子和前缀缓存的请求引用循环，GPU worker 进程内存溢出被杀——再漂亮的引用计数，真循环起来一样漏，生产内存还得自己盯监控
- **llm-d 团队 benchmark（2026-04）**：16 块 H100 跑 Qwen-32B、150 个客户各 6000 token 共享系统提示词，前缀缓存感知调度把 P90 首 token 延迟从 93 秒降到 0.542 秒——170 倍
- **FutureAGI 评估（2026-04）**：KV-cache 命中率低于 0.55 时，RAG 应用 Groundedness 评分从 0.88 跌到 0.69，工具调用参数开始丢失——命中率低不只是慢，是模型开始犯傻
- **llm-d 团队（2026-04）**：单实例里首 token 延迟从 4.3 秒降到 0.6 秒；挂上传统负载均衡器，相同前缀被分散到不同机器，缓存反复被驱逐重算——分布式前缀缓存还不是开箱即用，要拿得自己搭全局索引
