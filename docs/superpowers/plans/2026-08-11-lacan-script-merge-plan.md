## 2. 符号/公式口播策略（本次改稿核心）

### 2.1 认脸制（一生一次）
每个符号首次出现 = **认脸仪式**，四件套：① 形状描述（长什么样）→ ② 名字（正式名）→ ③ 一句话含义 → ④ 短别名（此后一律用它）。
之后该符号**不再重复认脸**，只用别名 + 关键处回扣一次形状（帮视觉记忆）。

### 2.2 别名词典（拉康欲望图专属，写进 writer 契约级纪律）

| 符号 | 正式名 | 认脸形状锚点 | 短别名（对话一律用） |
|---|---|---|---|
| S1 | 原初能指/主人能指 | "一个字立起来，像桩子" | **桩子词** |
| S2 | 知识能指链 | "桩子后面跟着的那串" | **链条** |
| $ | 划杠的主体 | "一个 S 被横着砍了一刀" | **划杠的人**（少用"划杠 S"） |
| ΔS | 欲望的向量 | "马蹄形的线，穿过链两次" | **马蹄线** |
| s(A) | 大他者的缺位能指 | "大他者缺的那个词的记号" | **缺位词** |
| i(a) | 小他者的形象 | "照镜子看到的那张脸" | **镜中像** |
| 对象 a | 欲望的对象小 a | "缺口里塞着的小零件" | **小 a** |
| A | 大他者 | "那个被当作全知全能的它" | **大他者**（语义名，非符号） |
| S(A/) | 被划杠的大他者 | "大他者也被砍了一刀" | **缺位的大他者** |
| S◇a | 欲望公式 | "上面划杠的人，下面小 a，中间菱形像沙漏" | **沙漏公式** |

### 2.3 符号串禁令
- 一段对话内 **≥2 个不同符号未先认脸** → 必须拆开，换语义名。
- 口头绝不念"小写 s、大写 S、中间一杠"这类逐字符读法（现状 ep01 有 6 处，清零）。

### 2.4 公式读法三句法
公式不给"逐字读"，给**结构一句话**：
1. 形状：长得像什么（沙漏/马蹄/跷跷板）
2. 部件：哪几个符号在场（说语义名，不说字母）
3. 动作：公式在干什么（"上压着下""绕回来穿过两次"）

### 2.5 全图期空间导航（ep08）
给听众"图上的位置"口播坐标：从下往上走（桩子词 → 链条 → 马蹄线 → 镜中像 → 缺位词 → 沙漏公式），每站报一次"我们现在在图的下半层/左上角"。听众闭眼有空间感，不再怕公式。

### 2.6 对话纪律：S3 用语义名逼问
S3 提问一律不用符号字母（"那个打叉的人又来了？"），逼 S2 用口语解释——把符号消化成本义再出口。
